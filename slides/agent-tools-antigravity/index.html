지금의 대화형 AI에도 도구가 있어요. 제품의 세대보다 ‘일하는 방식’의 차이입니다.

프롬프트는 사라지지 않습니다. 같은 자연어 요청에 파일과 도구, 실행 권한이 연결되면서 AI가 실제 작업을 수행할 수 있게 된 것입니다. ‘예전 챗봇은 언제나 답변만, 요즘 제품은 언제나 자율 실행’이라는 연대기나 이분법은 피합니다. 현대 대화형 서비스도 검색·파일 생성 등의 도구를 사용할 수 있습니다.

예: 책모임 안내문을 채팅에 써 주는 것과, 내 연습 폴더에 브라우저로 열 수 있는 안내 파일을 만드는 것을 비교해 설명합니다.

AI 모델을 ‘이해하고 생각하는 부분’, 도구를 ‘손과 발’, 작업 폴더를 ‘함께 쓰는 책상’에 비유합니다. 터미널은 컴퓨터에 작업 명령을 전달하는 창입니다. 처음부터 명령어를 외울 필요는 없지만 실행 요청이 나오면 무슨 일을 하는지 확인해야 합니다. 파일 접근, 브라우저 사용 등은 제품·환경·설정에 따라 달라집니다.

Antigravity · AI-연습학습용 화면 모형

② 대화 — 원하는 일을 평소 말로 부탁하는 곳

세 영역을 눌러 역할을 확인합니다. 실제 제품의 패널 위치를 복제한 화면이 아니라 개념을 설명하는 모형입니다. Antigravity 2.0과 IDE, 버전에 따라 프로젝트·대화·파일·미리보기의 위치와 여는 방법은 다를 수 있습니다. 결과는 앱의 결과물 화면 또는 브라우저에서 확인합니다.

Agent는 일을 수행하는 AI, Artifact는 AI가 보여 주는 계획이나 결과물이라고 풀어 설명합니다. 용어 암기보다 ‘부탁할 곳’과 ‘결과를 확인할 곳’을 찾는 것이 목표입니다.

명령 실행·웹 접근의 권한 요청도 따로 확인해요.

새 대화에서 계획 중심 모드인 Planning을 선택하고, Settings의 Agent 탭에서 Artifact Review를 Request Review로 설정합니다. 공식 문서 기준으로 계획 검토 정책은 Planning 모드의 계획·변경 검토를 제어합니다. 설정 이름과 위치는 버전에 따라 바뀔 수 있습니다.

계획 검토와 실행 권한은 별개입니다. Request Review라는 같은 이름이 권한 프리셋에도 등장할 수 있습니다. 이 화면은 Artifact Review 정책을 말합니다. ‘항상 진행’이나 포괄적인 자동 허용은 이번 입문 실습의 전제가 아닙니다. 폴더 안 파일 읽기·쓰기가 매번 허락을 요구한다고 설명하지 않습니다.

복사 버튼을 누르고 Antigravity 대화 입력창에 붙여넣은 다음 전송합니다. 붙여넣기는 Windows의 Ctrl+V, macOS의 Command+V입니다. 줄바꿈 방법이나 전송 버튼은 앱 표시를 따릅니다. 키보드 Enter가 전송되는 설정에서는 여러 줄을 한꺼번에 붙여넣는 편이 편합니다.

‘설치 없이 열 수 있는 파일 하나’는 첫 작업에서 복잡한 개발 환경을 피하기 위한 실습 조건입니다. 사진·신청 정보·외부 서비스 연결은 넣지 않습니다. 입력의 개인정보나 기관 자료는 보내기 전에 확인합니다. 복사가 차단된 브라우저에서는 문장이 선택되므로 직접 복사합니다.

실제 Antigravity에서 Implementation Plan(작업 계획)을 읽습니다. 부탁한 정보가 맞는지, 불필요한 프로그램 설치나 다른 파일 변경이 있는지, 외부 공개를 하려는지 봅니다. 모르면 ‘무엇이 바뀌는지 쉬운 말로 설명해 줘’라고 물어봅니다. 맞으면 Proceed(진행)를 누릅니다. 다르면 계획에 의견을 달거나 대화로 수정 요청을 합니다.

이 자료의 버튼은 연습용입니다. 실제 AI를 호출하거나 파일을 수정하지 않습니다.

앱 안에서 HTML 파일을 누르면 코드가 보일 수도 있습니다. 컴퓨터의 파일 탐색기(Windows) 또는 Finder(macOS)에서 AI-연습 폴더를 열고 안내.html을 두 번 클릭합니다. 다른 앱으로 열리면 ‘연결 프로그램’ 또는 ‘다음으로 열기’에서 Chrome·Edge·Safari 등 브라우저를 선택합니다.

AI가 만든 이름이나 위치가 다르면 정확한 파일 경로를 물어봅니다. 외부 설치가 필요 없는 단일 HTML을 요청했지만 다른 결과가 나왔다면 그 조건에 맞춰 다시 만들어 달라고 합니다. 실습 완료 예시는 앞 장 또는 마지막 장에서 열 수 있습니다.
