AI가 스스로 작업 순서를 정할 수 있어도 원하는 결과와 완료 기준은 사람이 정합니다. 계획을 읽고 범위를 맞춘 후 작업하게 하고, 결과물을 실제로 열어 확인합니다. 틀린 점이 있으면 한 가지씩 구체적으로 수정 요청을 합니다. 에이전트의 자체 검사가 사람의 최종 확인을 대신하지는 않습니다.

세 영역을 눌러 역할을 확인합니다. 실제 제품의 패널 위치를 복제한 화면이 아니라 개념을 설명하는 모형입니다. Antigravity 2.0과 IDE, 버전에 따라 프로젝트·대화·파일·미리보기의 위치와 여는 방법은 다를 수 있습니다. 결과는 앱의 결과물 화면 또는 브라우저에서 확인합니다.

Agent는 일을 수행하는 AI, Artifact는 AI가 보여 주는 계획이나 결과물이라고 풀어 설명합니다. 용어 암기보다 ‘부탁할 곳’과 ‘결과를 확인할 곳’을 찾는 것이 목표입니다.

복사 버튼을 누르고 Antigravity 대화 입력창에 붙여넣은 다음 전송합니다. 붙여넣기는 Windows의 Ctrl+V, macOS의 Command+V입니다. 줄바꿈 방법이나 전송 버튼은 앱 표시를 따릅니다. 키보드 Enter가 전송되는 설정에서는 여러 줄을 한꺼번에 붙여넣는 편이 편합니다.

‘설치 없이 열 수 있는 파일 하나’는 첫 작업에서 복잡한 개발 환경을 피하기 위한 실습 조건입니다. 사진·신청 정보·외부 서비스 연결은 넣지 않습니다. 입력의 개인정보나 기관 자료는 보내기 전에 확인합니다. 복사가 차단된 브라우저에서는 문장이 선택되므로 직접 복사합니다.

버튼은 제목 크기가 달라지는 예시를 보여 줍니다. 실제 실습에서는 Antigravity의 같은 대화에 수정할 부분과 유지할 부분을 말합니다. ‘더 예쁘게’보다 ‘제목을 두 배로’, ‘배경을 흰색으로’, ‘문장을 세 줄로’처럼 확인할 수 있는 요청이 좋습니다.

AI가 파일을 저장하면 열려 있는 브라우저를 새로고침합니다. Windows는 Ctrl+R, macOS는 Command+R입니다. 날짜·장소처럼 바뀌면 안 되는 정보가 유지됐는지도 다시 봅니다. 변경이 되지 않으면 현재 열어 본 파일과 AI가 수정한 파일이 같은지 확인합니다.

오류 메시지는 함께 보여 주세요. 사용량 제한·로그인 문제는 앱의 안내를 확인하세요.

진행 중인 작업을 멈추려면 앱의 중지(Stop) 버튼을 사용합니다. 말로 ‘멈춰’라고 쓰는 것만으로 이미 실행 중인 작업이 즉시 중단되거나 되돌아간다고 보장할 수는 없습니다. 멈춘 뒤 바뀐 파일을 확인하고, 원본이 필요하면 별도로 둔 백업을 사용합니다.

오류 문구나 화면을 제공할 때 개인정보는 가립니다. 계정·네트워크·한도 오류를 코드 오류로 오해해 반복 설치하지 않도록 합니다. 이 자료의 진행 메모와 마지막 공식 문서 링크에서 추가 안내를 확인할 수 있습니다.
