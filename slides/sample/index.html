새 발표자료
추가 방법

이 데크 자체가 새 발표의 본보기입니다.
→ 키 또는 화면 넘김으로 진행하세요.

1단계 — 폴더 복사

slides/sample/ 폴더를 복사해
slides/my-talk/처럼 새 이름을 붙입니다.

폴더 이름은 영문 소문자와 하이픈만 사용합니다.
이 이름이 곧 공유 주소가 됩니다:
https://dkdlqoddi.github.io/slides/my-talk/

2단계 — 내용 수정

index.html의 <section> 하나가 슬라이드 한 장입니다.

테마 교체: theme/black.css ↔ theme/white.css
전환 효과: Reveal.initialize의 transition 값
(none · fade · slide · convex · concave · zoom)

발표마다 테마·전환을 자유롭게 골라도
다른 발표에 영향을 주지 않습니다.

3단계 — 목록에 등록

저장소 루트의 slides.json에 항목 하나를 추가합니다.

{
  "title": "발표 제목",
  "date": "2026-08-01",
  "description": "한 줄 설명",
  "dir": "my-talk"
}

4단계 — 공개

main 브랜치에 push하면 몇 분 안에 공개됩니다.
방문자에 따라 목록 반영이 최대 10분 늦을 수 있습니다.

⚠ 슬라이드 도구(reveal.js 6.0.1)와 글꼴(Pretendard)은
vendor/의 공유 사본을 쓰므로 인터넷 없이도 동작합니다.

보너스 — 단계 공개

그림 설명: 복사, 수정, 등록 세 상자가 차례로 나타나며 화살표로 이어집니다.

화살표 키를 누르면 그림 조각이 차례로 나타납니다.

보너스 — 모핑

그림 설명: 세 상자가 왼쪽으로 좁혀지며 이동하고, 넷째 상자 공개가 더해집니다.

장을 넘기면 같은 상자가 미끄러지며 이어집니다.

끝.
