답변을 받음 ≠ 파일 저장·전송 완료

글을 잘 쓰는 조언자에게 초안을 부탁하는 장면을 떠올려 보세요. 역할을 이해하기 위한 비유이며 사람이 가진 의도나 책임이 있다는 뜻은 아닙니다. LLM이 저장했다고 말하는 것과 프로그램이 실제로 저장했다는 결과는 구분해야 합니다. 다음 장에서 실행 도구를 연결합니다.

2 · Agent 이해하기

Agent는 목표를 향해 작업하는 시스템

목표: “모임 안내 페이지를 파일로 만들어 줘.”

여기서는 LLM이 다음 행동을 고르고 도구의 결과를 받아 이어 가는 시스템을 Agent라고 부릅니다. 미리 정한 순서만 따르는 자동화와 구별할 수 있습니다. 제품에 따라 자율성과 사람의 개입 범위는 다릅니다. Anthropic · 에이전트의 동작 · 확인 2026-10-07.

2 · Agent 이해하기

LLM은 선택, 프로그램은 실행

요청 + 현재 자료 + 사용 가능한 도구

LLM의 선택은 도구 이름과 입력 같은 실행 요청으로 나옵니다. 이를 프로그램이 허용 범위 안에서 실행합니다. 결과나 오류가 다시 입력되면 다음 행동을 고릅니다. 사람이 매 단계 승인해야 한다는 뜻은 아니며 권한 설정에 따라 달라집니다. Anthropic · 에이전트의 동작 · 확인 2026-10-07.

2 · Agent 이해하기

결과를 보고 다음 행동을 바꿔요

가상 안내 페이지 만들기 · 학습용 실행 흐름

기준을 채우면 완료 · 막히면 사람에게 질문

실제 실행 기록이 아니라 직접 구성한 설명 예시입니다. 안내 파일을 열어 날짜 누락을 발견하면 수정 도구를 다시 호출하는 식으로 진행합니다. 반복 횟수나 시간에 제한을 둘 수도 있습니다. 완료 판단과 검토가 항상 정확하다는 보장은 없습니다. Anthropic · 에이전트의 동작 · 확인 2026-10-07.

2 · Agent 이해하기

Agent를 작은 사무실에 비유하면

역할을 이해하기 위한 비유입니다. AI가 사람처럼 의도·책임을 갖는다는 뜻은 아니에요.

앞서 만난 조언자에게 작업 진행 절차와 도구가 붙은 작은 사무실을 떠올립니다. 프로그램이라는 진행자가 LLM의 실행 요청을 도구에 연결하고 결과를 다시 전합니다. Agent는 이 전체 묶음입니다. 목표와 최종 책임을 맡는 사람은 바깥에 둡니다. 자체 제작한 교육용 비유입니다.

3 · 잘 맡기고 확인하기

생성과 검색은 서로 다른 일

검색 자료 → LLM → 답변 · 연결되어 있을 때 가능

답변이 자연스럽다고 해서 지금 인터넷을 검색했다는 뜻은 아닙니다. 검색 도구가 연결되면 외부 정보를 입력으로 가져와 답변에 사용할 수 있습니다. 내 파일도 연결되고 허용된 범위 안에서 접근합니다. 검색한 자료가 최신인지, 믿을 만한지도 별도로 확인합니다.

3 · 잘 맡기고 확인하기

자연스러운 문장도 틀릴 수 있어요

근거 없이 내용을 만들기도 해요. 날짜·숫자·출처를 확인.

사실과 다른 내용을 그럴듯하게 생성하는 문제를 환각 또는 허위 생성이라고 부릅니다. 화면의 시간 오류는 직접 넣은 교육 예시입니다. 같은 답을 여러 번 받는 것만으로 사실이라고 확정할 수 없습니다. Google · LLM의 원리 · 확인 2026-10-07.

3 · 잘 맡기고 확인하기

사람은 범위와 완료 기준을 정해요

“완료했어요”라는 답변 뒤에는 결과물을 직접 열기.

이 수업에서는 가상 자료로 안내문을 만들고 저장까지만 허용합니다. 삭제나 외부 전송처럼 영향이 큰 작업은 실행 전에 확인 지점을 두는 예입니다. 비밀번호와 불필요한 개인정보는 연습 자료에 넣지 않습니다. 서비스마다 도구와 권한 설정이 다르므로 실제 실습에서 확인합니다. 이런 범위 설정은 이 수업이 제안하는 사용 습관입니다.

3 · 잘 맡기고 확인하기

세 역할만 기억하세요

청중에게 파일 저장을 실제로 수행하는 쪽이 누구인지 물어보세요. LLM은 도구와 입력을 선택하고 프로그램과 도구가 실행합니다. 결과가 다시 LLM에 들어가는 흐름을 한 번 더 짚고, 사람은 목표·범위·최종 확인을 맡는다고 정리합니다.
