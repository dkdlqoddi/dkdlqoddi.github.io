E4 · EDA 실습: 문서 근거와 실패 처리

Python 3.10 이상과 표준 라이브러리만 사용합니다. 기본 모드는 고정 응답의 모의 모델이며 실제 LLM, 사내 계정, 외부 API를 호출하지 않습니다. 로컬 HTTP 요청과 도구·검증·종료 흐름은 실제로 실행됩니다.

전체 실습 ZIP ↓lab.pyfixtures.jsonMCP 서버

ZIP을 풀고 터미널에서 그 폴더로 이동합니다. Windows에서 python 명령이 없다면 설치 환경의 py -3를 사용하세요. 결과는 out/작업ID/trace.json에 저장됩니다. 검증 성공 때만 answer.json이 추가됩니다.

1. 원문을 먼저 확인

MockSTA는 이 수업의 가상 툴입니다. 실제 상용 툴에서 report_mock_timing을 실행하지 않습니다. fixtures.json의 r1 매뉴얼 §2는 출력 단위를 ns로 정의합니다. 가상 리포트는 SS 코너, slack −0.08 ns입니다.

python lab.py eda --scenario normal
python lab.py eda --scenario wrong-version
python lab.py eda --scenario denied
python lab.py eda --scenario missing
python lab.py selftest
시나리오예상 판정
normalcompleted · r1 / report_mock_timing / ns / manual-r1 / §2
wrong-versionhandoff / ground_truth_mismatch · r2 근거 반려
deniedhandoff / permission_denied · 재시도하지 않음
missinghandoff / not_found · 없는 문서로 답하지 않음

2. 실제 MCP stdio 메시지 보기

mcp_server.py는 MCP 2025-11-25의 초기화·tools/list·tools/call을 제공하는 작은 교육용 서버입니다. LLM 없이도 터미널에서 메시지를 직접 넣어 볼 수 있습니다. stdout에는 JSON-RPC만 출력합니다.

python mcp_server.py

아래 네 줄을 차례로 입력하세요. 두 번째 알림에는 응답이 없는 것이 정상입니다.

{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"course","version":"1"}}}
{"jsonrpc":"2.0","method":"notifications/initialized"}
{"jsonrpc":"2.0","id":2,"method":"tools/list"}
{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"manual_lookup","arguments":{"version":"r1","command":"report_mock_timing"}}}

실제 Agent에 연결할 때는 사용하는 클라이언트의 stdio MCP 설정에서 Python 실행 파일과 mcp_server.py의 절대 경로를 지정합니다. 연결 설정은 제품·버전마다 다릅니다. 서버는 모의 문서만 반환하고 임의 파일·셸·네트워크 접근 도구를 제공하지 않습니다.

3. Skill은 연결·권한과 별개

manual-review/SKILL.md는 질문 조건 확인→도구 호출→근거 검토의 지시 예시입니다. OpenCode에서는 프로젝트의 .opencode/skills/manual-review/SKILL.md에 둘 수 있습니다. 스킬 로딩 권한은 permission.skill에서 관리하며, MCP 연결과 도구 권한은 별도로 확인합니다.

4. 가상 리포트 검사와 제출

python lab.py selftest는 원문 리포트가 통과하고 코너·단위·부호·릴리즈가 바뀐 네 요약이 반려되는지도 검사합니다. validate_report는 요약을 독립된 원문 fixture와 대조하며 LLM의 자체 PASS를 사용하지 않습니다.

  • r1의 단위·명령·원문 절을 담은 answer.json
  • 잘못된 버전과 권한 거부가 인계된 trace.json
  • 가상 리포트의 코너·단위·부호를 보존한 검토 설명
  • 실제 설계 sign-off나 상용 툴 동작은 검증하지 않았다는 범위
