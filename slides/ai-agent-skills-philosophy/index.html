E2 · 공통 검증

실제로 관찰한 것만 기록합니다

task_id: demo-01
tool: manual_lookup
arguments: {"version": "r1"}
status: ok | denied | timeout
result_ref: manual-r1 / section-2
verification: passed | rejected | unresolved

도구 요청·결과는 실행 증거. 작성된 “Thought”는 내부 추론 로그가 아닙니다.

예시 로그는 기록 형식을 보여주기 위한 가상 자료입니다. 사람에게 보여줄 설명과 실제 시스템에서 관찰한 이벤트를 구분합니다.
