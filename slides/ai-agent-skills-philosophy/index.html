Philosophy

인공지능 코딩 도구들의 아키텍처와 작동 철학 비교

작동 구조와 핵심 원칙 중심 (사용법/명령어 제외)

ponytail

  • 게으른 시니어 개발자: "불필요한 코드는 작성하지 않는다"는 원칙(YAGNI)을 AI에게 주입하는 스킬 플러그인입니다.
  • 방어적 의사결정 사다리: 코드를 짜기 전 [정말 필요한가? ➔ 브라우저 내장 기능인가? ➔ 표준 라이브러리로 되나?]를 먼저 따지게 합니다.
  • 철학: 무분별한 의존성(npm 패키지 등) 추가를 막고 생성 토큰을 최소화하여, 코드베이스를 가볍고 유지보수하기 쉽게 지킵니다.

fablize

  • 증명 요구 (Proof): AI가 대충 작업하고 "완료했습니다"라고 선언하는 것을 중간에 가로채는 검증 하네스(Harness)입니다.
  • 완수 강제: 작업이 끝났다면 실제 테스트를 통과한 결과물이나 검증 로그(증거)를 제시해야만 게이트를 통과할 수 있습니다.
  • 철학: AI의 '착각'이나 '운'에 의존하지 않고, 신뢰할 수 있는 Task-completion(작업 완수)을 보장하는 규율 도구입니다.

grill-me

  • 역질문 인터뷰: 모호한 지시를 그대로 실행하지 않고, AI가 사용자에게 질문(인터뷰)을 던져 모호성을 제거하는 도구입니다.
  • 의도적 마찰 (Friction): AI가 스스로 추측해서 발생시키는 '자신감 있는 헛소리'를 차단하기 위해 의도적으로 진행을 늦춥니다.
  • 철학: 구현 전에 의사결정 트리의 모든 브랜치를 함께 해소하여, 코딩 전 완벽한 합의(Shared Understanding)를 이룹니다.

blindspot-flow

  • 사전 안전망: 코드를 쓰기 전, 개발자가 간과한 '맹점(Blindspot)'을 선제적으로 발굴하고 문서화하는 필수 프로세스입니다.
  • 체계적 흐름: 인터뷰 ➔ 미지 영역(Unknowns) 분석 ➔ 명세화(Explainer) ➔ 병합 전 퀴즈(Quiz)로 이어지는 4단계 규칙입니다.
  • 철학: AI가 작성한 결과물에 끌려가지 않고, 비개발자 리뷰어조차 변화를 정확히 통제하고 이해할 수 있도록 보장합니다.

superpower

  • 구조적 파이프라인: 프라임 레디언트 팀이 만든 Claude Code용 프레임워크로, [구상 ➔ 계획 ➔ 실행]의 엄격한 3단계 과정을 강제합니다.
  • 안전장치: AI가 무작정 코드를 먼저 짜는 'Vibe Coding'을 막고, 설계도 작성을 최우선으로 요구합니다.
  • 철학: TDD(테스트 주도 개발)와 체계적인 디버깅 하네스를 내장하여, 시니어 엔지니어의 규율 잡힌 작업 방식을 AI에 주입합니다.

oh-my-opencode

  • 역할 분담: 단일 AI 모델의 한계를 극복하기 위해 Sisyphus 오케스트레이터가 작업을 쪼개고 서브 에이전트들에게 분배합니다.
  • 팀 구성: 리서치(Librarian), 정적 분석(AST-Grep), 언어 서버(LSP) 모듈들이 하나의 팀처럼 병렬 구동됩니다.
  • 철학: AI가 모든 것을 혼자 처리하는 대신, 전문 도구들과 협력하는 '매니저' 역할을 수행하도록 강제합니다.

LangChain Data Agent

  • 확장성: 단일 LLM의 한계를 넘기 위해 여러 외부 도구(Tools)와 데이터베이스를 AI에게 연결하는 모듈형 아키텍처입니다.
  • ReAct 패턴: 라우터 에이전트가 "생각(Reasoning) ➔ 도구 선택 및 실행(Acting) ➔ 관찰(Observation)"의 주기를 반복하며 정답을 추론합니다.
  • 철학: AI를 단순한 텍스트 생성기가 아닌, 사내 시스템 및 복잡한 워크플로우 전반을 제어하는 오케스트레이터로 활용합니다.

Aider

  • 터미널 기반: 에디터 플러그인이 아닌 CLI 환경에서 동작하며, 로컬 샌드박스의 파일과 직접 상호작용하는 페어 프로그래밍 AI입니다.
  • Git 연동: 코드를 수정한 뒤 자동으로 변경 사항을 커밋(git commit)하여 작업 이력을 깔끔하게 분리하고 보존합니다.
  • 철학: 테스트 실패 메시지나 린트 에러를 터미널에서 즉각 피드백 받아, 반복 루프(Loop)를 돌며 스스로 오류를 고치는 신속함이 핵심입니다.

Copilot Workspace

  • 플랫폼 통합: 로컬 에디터를 벗어나 GitHub Issue에서 시작하여 PR 생성으로 끝나는 클라우드 네이티브 파이프라인입니다.
  • 명세 중심: 코드를 바로 생성하는 대신, 요구사항(Spec)과 계획(Plan)을 먼저 작성하여 개발자가 개입 및 궤도 수정을 할 수 있게 합니다.
  • 철학: AI가 프로젝트 전반의 문맥을 이해하고, '이슈 기반 개발(Issue-Driven Development)'의 전 과정을 엔드투엔드로 보조합니다.

Devin

  • 완전 자율 실행: 사람의 중간 개입 없이, 부여된 고수준 목표를 달성하기 위해 샌드박스 내부에서 수백 단계의 논리적 사고를 이어갑니다.
  • 도구 사용(Tool Use): 내부 브라우저로 API 문서를 검색하고, 에디터로 코드를 작성하며, 터미널로 서버를 실행해 검증까지 모두 스스로 수행합니다.
  • 철학: AI를 단순한 코드 추천 도구(Copilot)가 아니라, 독립적으로 임무를 완수하는 '소프트웨어 엔지니어' 동료로 격상시킵니다.
