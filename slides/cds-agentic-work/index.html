정책 조회

어느 폴더가 열려 있는지 확인

모두 17개입니다. 다섯 묶음으로 나뉩니다.

핵심은 미리 등록해 둔 작업입니다. 등록한 것만 돌아갑니다.
아무 명령이나 실행되지 않습니다.

제한은 어디에서 나오나요

1. 도구 목록

열어 둔 17개 밖의 일은 할 수 없습니다.

2. 폴더 설정

폴더마다 읽기·쓰기·명령 실행을 따로 정합니다.

3. 작업 목록

관리자가 등록한 명령만 실행됩니다.

제한은 설정에서 나옵니다.

그래서 설정을 어떻게 잡느냐가 전부입니다.

그래서 설정이 전부입니다

폴더를 좁게 잡으면 안전합니다.
넓게 잡으면 그만큼 그대로 열립니다.

그런데 어느 폴더를 열어야 하는지는
그 업무를 하는 분만 알 수 있습니다.

이 이야기는 뒤에서 다시 부탁드리겠습니다.

흔한 오해 하나

"허용 목록을 만들었으니 안전하다"

허용 목록은 이름을 글자 그대로 맞춰 봅니다.
그래서 빈틈이 생깁니다.

허용 목록은 실수를 막는 장치입니다.
악의를 막는 장치가 아닙니다.

진짜 방어는 두 가지입니다. 폴더를 좁게 잡는 것,
그리고 되돌릴 수 있게 만드는 것입니다.

지금 어디까지 왔나요

1. 구조 설계 2. 구현 3. 개발망 연결 확인 4. 사내 실환경 확인 5. 실제 업무 적용

다섯 단계 중 셋째 단계입니다. 아직 진행 중입니다.

AI 코딩 도구가 중개 서버에 붙는 것까지는 확인했습니다.
사람 없이 도는 자동 실행 전체는 사내 환경에서 아직 돌려보지 않았습니다.

왜 Domain 협조가 필요한가

여기서 말하는 Domain 담당자는
각 업무 영역의 데이터와 시스템을 실제로 아는 분입니다.

기존 문서의 "데이터 소유 부서", "운영자"와 같은 분들입니다.

무엇을 자동화할지는
그 업무를 하는 사람만 압니다.

구조는 준비됐지만 등록된 업무 자동화는 아직 없습니다.
빈 그릇이 준비되어 있는 상태입니다.

요청 1단계

절차를 글로 내려 주세요

실행 대리 프로그램이 그대로 따라 할 수 있는
완전한 절차를 부탁드립니다.

형상관리 도구(Perforce) 연동을 포함해 주세요.
권한 전환 명령(newgrp)도 포함해 주세요.
환경변수 설정도 포함해 주세요.

제출한 절차가 오늘 바로 실행되지는 않습니다.
그래도 글로 남기는 것이 이번 요청의 목적입니다.

"완전하다"는 무슨 뜻인가요

  1. 화면 꾸밈이나 터미널 기능에 기대지 않는가.
  2. 필요한 환경변수를 스스로 선언하고 없으면 즉시 멈추는가.
  3. 어느 폴더에서 실행해도 결과가 같은가.
  4. 중간이 실패하면 거기서 멈추는가.
  5. 확인을 묻는 명령에 자동 응답이 붙어 있는가.
  6. 종료 코드의 뜻이 표로 적혀 있는가.

이 여섯은 실행 가능성만 봅니다.
형상관리 도구와 권한 전환이 들어갔는지는 따로 확인합니다.

가장 자주 걸리는 한 가지

사람이 쓰는 터미널은 시작 설정 파일을 읽습니다.
사람이 지켜보지 않는 실행은 그 파일을 읽다가 중간에 멈춥니다.

결과는 이렇습니다.
내 터미널에서 잘 되던 명령이
"명령을 찾을 수 없다"고 뜹니다.

그래서 스크립트가 필요한 환경변수를 스스로 선언해야 합니다.
위 판정 기준 2번이 이것입니다.

권한 전환 명령의 함정

newgrp은 지금 셸을 새 셸로 갈아치웁니다.
스크립트 안에서 부르면 그 아래 줄이 실행되지 않습니다.

실행 대리 프로그램에게는 멈춘 것처럼 보입니다.

1순위

그룹 전환 자체를 없앱니다. 계정 설정이나 폴더 설정으로 미리 해결합니다.

2순위

스크립트 첫머리에서 자기 자신을 다시 실행합니다.

3순위

명령 하나만 감쌉니다. 감싼 명령이 다른 셸에서 도는 함정이 있습니다.

요청 2단계

직접 한 번 써 보세요

Opencode로 업무 자동화와 분석 자동화를
직접 시도해 보시기 바랍니다.

완성이 목적이 아닙니다.
어디서 막히는지 알아내는 것이 목적입니다.

막힌 지점이 곧 다음에 열어야 할 도구 목록이 됩니다.
실패한 시도도 결과입니다. 그대로 알려 주세요.

요청 3단계

확정하고 안전하게 만드세요

Domain 안에서 여러 사람이 같은 방법을 쓰게 되면
그것을 확정합니다.

확정한 것을 재사용 절차와 실행 스크립트로 만듭니다.

그리고 앞서 말씀드린 것,
어느 폴더를 열지 정하는 일도 이 단계에 포함됩니다.

"안전하다"는 무슨 뜻인가요

새 규칙이 아닙니다. 이미 쓰고 있는 약속입니다.

  • 인자는 정해진 개수만 받는다.
  • 성공하면 정해진 종료 코드와 결과 파일을 남긴다.
  • 성공과 실패를 출력 첫 줄에 고정 문구로 알린다.
  • 여러 번 실행해도 결과가 같아야 한다.
  • 되돌릴 수 없는 동작은 스크립트 맨 위에 경고로 적는다.

네 번째가 중요합니다. 실패하면 자동으로 다시 돌기 때문입니다.
