AI 코딩 도구 운영 방법과
Domain 협조 요청

2026-07-30 · 우제율

구조는 만들었습니다.
이제 여러분의 지식이 필요합니다.

오늘은 알려드리는 자리이자 부탁드리는 자리입니다.

발표가 끝나면 각 Domain에 할 일이 세 가지 생깁니다.

두 망은 나뉘어 있고 직접 연결이 없습니다

그림 설명: 사무망과 가상작업공간이 나란히 있고 둘 사이에 직접 연결이 없습니다.

보호 대상 데이터가 있어, AI 코딩 도구를 안에서 직접 돌릴 수 없습니다.

그래서 사이에 중개 서버를 두었습니다

그림 설명: 사무망과 가상작업공간 사이에 중개 서버가 생기고, 양쪽이 중개 서버를 거쳐서만 이어집니다.

건물 안내 데스크와 같습니다. 정해진 용무만 대신 처리해 줍니다.

입구는 둘이고 중개 서버는 하나입니다

그림 설명: 왼쪽에 입구 두 개가 있습니다. 하나는 Opencode이고 다른 하나는 API 서버입니다. 두 입구가 각각 가운데 중개 서버로 연결됩니다. 중개 서버만 오른쪽 가상작업공간에 닿습니다.

세 시스템이 한 줄로 이어진 구조가 아닙니다. 두 입구는 형제 관계입니다.

두 입구는 기능이 같고 붙는 방법만 다릅니다

그림 설명: 원격 연결과 웹 주소 호출 두 방식이 하나의 지점으로 모여 같은 중개 서버로 들어갑니다.

중개 서버에 직접 붙을 수 없는 PC를 위해 웹 주소 방식을 하나 더 엽니다.

열어 둔 도구는 다섯 묶음, 열일곱 개입니다

17

파일 읽기 파일 쓰기 미리 등록해 둔 작업 분석 정책 조회

핵심은 미리 등록해 둔 작업 — 등록한 것만 돌아갑니다.
아무 명령이나 실행되지 않습니다.

제한은 설정에서 나옵니다

그림 설명: 도구 목록, 폴더 설정, 작업 목록 세 가지가 모두 하나의 설정으로 모입니다.

그래서 설정을 어떻게 잡느냐가 전부입니다.

어느 폴더를 열지는 그 업무를 하는 분만 압니다

그림 설명: 좁게 잡은 폴더는 안전하고, 넓게 잡은 폴더는 잡은 만큼 그대로 열립니다.

이 이야기는 뒤에서 다시 부탁드리겠습니다.

허용 목록은 실수를 막는 장치입니다

"허용 목록을 만들었으니 안전하다"

이름을 글자 그대로 맞춰 보기 때문에 빈틈이 생깁니다.
실수는 막습니다. 악의는 못 막습니다.

진짜 방어는 두 가지 — 폴더를 좁게 잡는 것,
되돌릴 수 있게 만드는 것입니다.

다섯 단계 중 셋째 단계를 지나고 있습니다

1. 구조 설계 2. 구현 3. 개발망 연결 확인 4. 사내 실환경 확인 5. 실제 업무 적용

AI 코딩 도구가 중개 서버에 붙는 것까지 확인했습니다.
사람 없이 도는 자동 실행 전체는 아직입니다.

무엇을 자동화할지는 그 업무를 하는 분만 압니다

0

지금 등록된 업무 자동화 개수

구조는 준비됐지만 그릇은 비어 있습니다.
여기서 말하는 Domain 담당자는 각 업무 영역의
데이터와 시스템을 실제로 아는 분입니다.

기존 문서의 "데이터 소유 부서", "운영자"와 같은 분들입니다.

요청 1단계

절차를 글로 내려 주세요

그림 설명: 절차가 적힌 문서 한 장을 뜻하는 그림입니다.

실행 대리 프로그램이 그대로 따라 할 수 있는 완전한 절차,
아래 셋을 반드시 포함해서 부탁드립니다.

형상관리(Perforce) 연동 권한 전환(newgrp) 명령 환경변수 설정

제출한 절차가 오늘 바로 실행되지는 않습니다.
그래도 글로 남기는 것이 이번 요청의 목적입니다.

"완전하다"는 여섯 판정 기준을 뜻합니다

1 · 화면 꾸밈이나 터미널 기능에 기대지 않는다
2 · 환경변수를 스스로 선언하고 없으면 멈춘다
3 · 어느 폴더에서 실행해도 결과가 같다
4 · 중간이 실패하면 거기서 멈춘다
5 · 확인을 묻는 명령에 자동 응답이 붙어 있다
6 · 종료 코드의 뜻이 표로 적혀 있다

이 여섯은 실행 가능성만 봅니다.
형상관리와 권한 전환 포함 여부는 따로 확인합니다.

내 터미널에서 되던 명령이 "찾을 수 없다"고 뜹니다

그림 설명: 사람이 쓰는 터미널은 시작 설정 파일을 읽어 성공하지만, 사람이 지켜보지 않는 자동 실행은 같은 명령이 실패합니다.

그래서 스크립트가 필요한 환경변수를 스스로 선언해야 합니다. 판정 기준 2번입니다.

권한 전환 명령은 셸을 통째로 갈아치웁니다

그림 설명: 스크립트 중간의 권한 전환 명령 아래 줄들이 실행되지 않고 끊깁니다.

1순위

그룹 전환 자체를 없앱니다. 계정·폴더 설정으로 미리 해결합니다.

2순위

스크립트 첫머리에서 자기 자신을 다시 실행합니다.

3순위

명령 하나만 감쌉니다. 다른 셸에서 도는 함정이 있습니다.

요청 2단계

직접 한 번 써 보세요

그림 설명: 직접 시도하면 막힌 지점이 나오고, 막힌 지점이 다음에 열 도구 목록이 됩니다.

완성이 목적이 아닙니다. 어디서 막히는지가 목적입니다.

실패한 시도도 결과입니다. 그대로 알려 주세요.

요청 3단계

확정하고 안전하게 만드세요

그림 설명: 여러 사람이 같은 방법을 쓰게 되면 확정하고, 확정한 것을 절차와 실행 스크립트로 만듭니다.

앞서 말씀드린 어느 폴더를 열지 정하는 일도
이 단계에 포함됩니다.

"안전하다"는 이미 쓰는 다섯 약속을 뜻합니다

인자는 정해진 개수만 받는다
정해진 종료 코드와 결과 파일을 남긴다
성공·실패를 출력 첫 줄 고정 문구로 알린다
재실행해도 결과가 같다
되돌릴 수 없는 동작은 맨 위에 경고로 적는다

넷째가 중요합니다. 실패하면 자동으로 다시 돌기 때문입니다.
새 규칙이 아니라 이미 쓰는 약속입니다.
