DX와 AX: 무엇이 다른가

그림 설명: 왼쪽에 DX(디지털 전환)의 4가지 특성, 오른쪽에 AX(AI 전환)의 4가지 특성이 나열되고, 가운데 화살표로 진화 방향을 표시합니다.

규칙 기반 vs LLM 기반 자동화

그림 설명: 상단은 규칙 기반 자동화로 입력에서 조건 분기를 거쳐 처리하는 고정 흐름이고, 하단은 LLM 기반으로 입력을 LLM이 판단하여 유연하게 처리하는 흐름입니다.

DX 자동화 흐름

그림 설명: DX 자동화의 선형 파이프라인으로 데이터 수집, 규칙 분기, 고정 처리, 결과 출력 네 단계가 화살표로 이어집니다.

선형적 · 고정된 규칙 · 예외에 취약

AX 자동화 흐름 — DX 대비 확장

그림 설명: 상단에 DX 흐름이 흐리게 표시되고, 하단에 AX 흐름이 시안색으로 강조됩니다. 각 단계별로 무엇이 바뀌었는지 수직 화살표와 라벨로 연결합니다. AX에서 새로 추가된 자연어 이해, 맥락 기억, 자기 치유, 피드백 루프가 시안 점선 상자로 표시됩니다.

방법 1 (난이도 하): subprocess + opencode

그림 설명: Python 스크립트가 subprocess를 통해 opencode CLI를 호출하고, opencode가 사내 LLM에 요청을 전달하는 구조입니다.

import subprocess

# 터미널에 opencode가 설치되어 있어야 합니다 (pip install opencode)
prompt = "현재 디렉토리의 파일 개수를 세어줘"

result = subprocess.run(
    ["opencode", "--headless", "-p", prompt],
    capture_output=True, 
    text=True
)

print(result.stdout)
# 출력 예시: 
# "현재 디렉토리에는 총 15개의 파일이 있습니다."

외부 도구 의존 · 설정 직관적 · 순수 텍스트 입출력

방법 2 (난이도 중하): HTTP 직접 호출

그림 설명: Python에서 requests 라이브러리로 사내 LLM API를 직접 호출하는 가장 단순한 구조입니다.

import os, requests

# 사전 준비: pip install requests
base_url = os.getenv("LLM_BASE_URL", "http://internal-llm/v1")
api_key = os.getenv("LLM_API_KEY", "사내토큰")

resp = requests.post(
    f"{base_url}/chat/completions",
    headers={"Authorization": f"Bearer {api_key}"},
    json={
        "model": "사내모델-v1",
        "messages": [{"role": "user", "content": "REST API가 뭐야?"}]
    }
)

# JSON 파싱하여 실제 응답 텍스트만 추출
content = resp.json()["choices"][0]["message"]["content"]
print(content)
# 출력 예시: "REST API는 웹 서비스 아키텍처 스타일입니다..."

외부 의존성 거의 없음 · 프로그래밍 기본 · 폐쇄망에 최적

방법 3 (난이도 중): OpenAI SDK 직접 사용

그림 설명: Python에서 OpenAI SDK의 base_url을 사내 LLM 주소로 지정하여 직접 연결하는 구조입니다.

import os
from openai import OpenAI

# 사전 준비: pip install openai
client = OpenAI(
    base_url=os.getenv("LLM_BASE_URL", "http://internal-llm/v1"),
    api_key=os.getenv("LLM_API_KEY", "사내토큰")
)

resp = client.chat.completions.create(
    model="사내모델-v1",
    messages=[
        {"role": "user", "content": "Python의 장점을 하나만 말해줘"}
    ]
)

print(resp.choices[0].message.content)
# 출력 예시: "가독성이 뛰어난 간결한 문법입니다."

가볍고 타입 힌트 완벽 · 비동기/스트리밍 완벽 지원

방법 4 (난이도 상): Langchain + 사내 LLM

그림 설명: Python에서 Langchain 라이브러리를 통해 HTTP API로 사내 LLM에 연결하는 구조입니다.

import os
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate

# 사전 준비: pip install langchain-openai
llm = ChatOpenAI(
    base_url=os.getenv("LLM_BASE_URL", "http://internal-llm/v1"),
    api_key=os.getenv("LLM_API_KEY", "사내토큰"),
    model="사내모델-v1"
)

# 프롬프트 템플릿과 LLM을 연결 (체인 구성)
prompt = ChatPromptTemplate.from_template("{topic}에 대해 1줄로 요약해줘")
chain = prompt | llm

result = chain.invoke({"topic": "Langchain"})
print(result.content)
# 출력 예시: "LLM 애플리케이션 개발을 돕는 강력한 프레임워크입니다."

가장 높은 추상화 · 체인 및 프롬프트 템플릿 등 강력한 기능
