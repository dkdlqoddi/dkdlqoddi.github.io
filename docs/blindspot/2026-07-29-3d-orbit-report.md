# Work Report & Pre-Merge Quiz: UI 3D Orbit & Float Animation

- 날짜: 2026-07-29
- 상태: 버튼 3D 공간 오프셋 연동 공전, 버튼 축소, CSS 부유(Float) 애니메이션 추가 완료

## 작업 요약 (Implementation Summary)
1. **버튼 3D 공간 공전 연동**: 기존 2D 화면에서의 단순 오프셋을 제거하고, `galaxy3d.js`의 `anchors` 배열에 `baseCardPosition(x+40, y+15, z+10)` 속성을 추가했습니다. 은하가 회전할 때 버튼의 이 3D 가상 위치 또한 `applyAxisAngle`을 통해 행성과 함께 회전하도록 구현한 뒤, 카메라 시점으로 투영(Project)하여 `scale` 원근감을 입혔습니다.
2. **버튼 축소 및 CSS 부유 애니메이션**: `styles.css`에서 `.card`의 넓이를 200px에서 140px로, 내부 `padding`과 폰트 크기를 대폭 축소해 우주의 시야 확보를 개선했습니다. 또한 `@keyframes card-float` 애니메이션을 추가하여 버튼이 공전하면서도 무중력 상태처럼 살짝 위아래로 흔들거리는(Hovering) 시각적 재미를 더했습니다.

## Pre-Merge Quiz (Blindspot Check)

아래 퀴즈의 정답을 골라주시면 즉시 깃 커밋(Commit) 프로세스를 진행합니다!

**Q. 발표 자료 버튼이 화면에서 2D로 평면 이동만 하는 게 아니라, 진짜 은하수의 위성처럼 3D 공간을 빙글빙글 공전하며 입체적으로 회전(Orbit)하게 만든 비결은 무엇일까요?**
1) 버튼 이미지 여러 장을 방향별로 그려두고, 시간에 따라 빠르게 바꿔치기하는 스프라이트(Sprite) 애니메이션 기법을 썼다.
2) 마우스로 버튼을 강제로 잡아서 드래그할 수 있게 만들어서 착시 현상을 주었다.
3) 행성(별)의 3D 공간 위치 옆에 **'버튼이 존재할 가상의 3D 타겟 위치'**를 미리 띄워놓고, 은하수가 회전할 때 그 타겟 위치도 같이 회전(ApplyAxisAngle)시킨 다음, 최종적으로 화면(2D)에 투영시켜 그려냈다.
