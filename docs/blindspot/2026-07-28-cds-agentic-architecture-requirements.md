# cds-agentic-architecture 요구사항

- 날짜: 2026-07-28
- 상태: 확정
- 관련 문서: 없음

## 요청 배경

발표자료에 불필요한 설명을 덜어내고 핵심 구조를 명확히 전달해야 합니다. 시스템 전체 구조인 오픈코드, API 서버, MCP 서버, 가상 작업망(VWP) 연결을 시각적으로 보여주어야 합니다. 가상 작업망에서 도메인 담당자가 에이전트를 돕기 위해 수행할 작업(반도체 설계 툴 환경 구성 및 로그 분석 등)을 구체적으로 설명해야 합니다.

## Unknowns 4분면

| 분면 | 항목 |

| Unknown Unknowns (미지 영역 — blindspot-pass 대상) | SVG 다이어그램 구현 시 시각 장애인용 대체 텍스트 구성 방안. 각 환경 구성 스크립트(newgrp, perforce)의 실제 동작 제약사항. |

## 확정 요구사항

1. 순차 애니메이션 구조: 구성 요소가 한 번에 나타나지 않도록, Reveal.js의 `data-auto-animate`를 활용해 여러 `<section>` 슬라이드로 분할하여 순차적으로 전개되도록 구성합니다. (인터뷰 답변 1)
2. 가로 단계형 레이아웃: 가상 작업망 내부 작업은 순서를 나타내는 가로 알약 모양(`.steps`) 컴포넌트로 여러 역할을 순서대로 배치합니다. (인터뷰 답변 2)
3. 담당자 작업 반영: 채팅으로 전달된 텍스트(1. 툴 설정값 정의 원칙, 2. newgrp/source/perforce 등 툴 실행 스크립트 환경 세팅, 3. 로그 분석을 통한 결정 인자 도출)를 그대로 최종 발표 내용으로 확정하여 슬라이드에 반영합니다. (인터뷰 답변 3)
