# Requirements Interview: LOG INDEX & Dynamic Coordinates

랜딩 페이지(`index.html`)의 LOG INDEX 텍스트 수정 및 하단 푸터(footer)의 정적 위도/경도를 마우스 좌표 기반으로 갱신하는 기능에 대한 분석을 완료했습니다.

기능 자체는 마우스 위치(X, Y)를 전 세계 경도(-180~180)와 위도(-90~90) 비율로 변환하여 순수 자바스크립트로 구현(`main.js` 추가)하는 것으로 방향을 잡았습니다. 구현에 앞서 완벽한 마감 처리를 위해 아래 **3가지 질문**에 대한 방향을 결정해 주시면 감사하겠습니다.

---

### 1. 모바일(터치) 환경 대응 정책
스마트폰이나 태블릿처럼 마우스 커서가 없는 기기에서는 현재 위치(마우스 오버) 좌표를 어떻게 표현하는 것이 가장 자연스러울까요?
- [A] 사용자가 화면을 스와이프/드래그 할 때만 좌표 갱신 (터치가 끝나면 멈춤)
- [B] 스마트폰 기기의 자이로스코프(기울기) 센서를 감지하여 좌표 갱신 (가장 동적임)
- [C] 모바일 기기에서는 기존처럼 정적 좌표(37.53°N · 127.02°E)를 고정 유지

### 2. 렌더링 성능 최적화 적용 여부
마우스가 1픽셀만 움직여도 즉시 문자를 변경하면 브라우저 렌더링 부하(DOM 업데이트)가 지속적으로 발생합니다.
- [A] `requestAnimationFrame`을 적용해 브라우저 주사율에 맞춰 부드럽게 최적화 적용 (권장)
- [B] 단순 이벤트 리스너 방식 유지 (구현은 가장 심플함)

### 3. 레이아웃 흔들림(Layout Shift) 억제 방안
좌표 숫자가 "11.11°" 에서 "88.88°" 로 변할 때 글자 폭이 달라 푸터 전체가 미세하게 떨릴 수 있습니다.
- [A] CSS의 `font-variant-numeric: tabular-nums;` (고정폭 숫자) 속성을 적용하여 떨림 완벽 억제 (권장)
- [B] 별도의 CSS 처리 없이 자연스러운 텍스트 폭 유지
