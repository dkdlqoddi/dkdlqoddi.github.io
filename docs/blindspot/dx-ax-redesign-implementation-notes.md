## 2026-08-19 22:45 — 짝 전환 슬라이드에 자동 페이드 차단 속성 사용

- 이유: 짝 없는 요소(약점 표시, 확장 상자)가 fragment인데, 자동 페이드와 fragment 숨김이 겹치면 전환 중 깜빡임 위험
