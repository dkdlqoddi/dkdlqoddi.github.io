# Work Report: 다이어그램 구체화 및 시각적 개선

## 1. 개요
* **목표:** 사용자 요청에 따라 세 가지 방법론 다이어그램에서 `Harness`가 LLM을 직접 감싸고 통제하는 구조를 명확히 하고, S3 마운트의 시각적 강조 및 배경 투명도 조절 수행.

## 2. 세부 변경 사항
1. **Harness 구조 변경 (방법론 1~3 공통)**
   - 기존에는 `Harness`가 후단에 위치한 별도의 노드였으나, 세 가지 방법론 모두에서 `Harness`가 `LLM+Opencode`를 캡슐처럼 감싸고 있는 형태로 SVG 다이어그램을 변경했습니다.
   - 방법론 1(MCP Server 기반)에서는 기존 `Harness` 자리에 `API Server`를 배치하여, Harness(통제) → API Server → MCP Server로 이어지는 흐름을 명확히 했습니다.
   - 장점 텍스트 또한 "API Server와 MCP Server가 위험한 요청을 필터링하고 통제함"으로 수정 완료했습니다.

2. **방법론 2 (S3 Server) 시각 강조**
   - VWP망에서 읽어오는 S3 오브젝트 마운트 화살표를 점선(Dashed) 패턴으로 바꾸고, **"🔒 Read-Only 마운트"**라는 강조된 주황색 배지를 부착하여 시각적으로 눈에 훨씬 잘 띄게 개선했습니다.

3. **Galaxy 배경 투명도 하향**
   - CSS의 `#galaxy-3d-bg`에 `opacity: 0.15` 속성을 부여하여, 우주 배경이 본문(다이어그램) 렌더링을 방해하지 않고 덜 눈에 띄도록(더 투명하게) 조절했습니다.
