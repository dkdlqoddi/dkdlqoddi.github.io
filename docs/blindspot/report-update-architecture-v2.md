# Work Report: VWP망 파일 연동 3가지 방법론 시각화

## 1. 개요
* **목표:** VWP망의 파일 시스템에 접근하여 분석을 수행하기 위한 3가지 방법론을 시각적으로 구현.
* **배경:** "어떤 방법론이 좋은 결과를 만들면서 보안적으로 안전한지 동등한 위치에서 테스트"하기 위해, 하나의 방법론(MCP Server)에 편중되어 있던 기존 슬라이드를 전면 교체.

## 2. 세부 변경 사항
1. **방법론 1: MCP Server 기반 통제형**
   - 오피스망의 LLM이 `Harness`를 통해 1차 필터링을 거치고, VWP망 내부에 위치한 `MCP Server`를 찔러 파일에 접근하는 고전적 통제 구조를 구현했습니다.
2. **방법론 2: S3 Server 기반 우회형**
   - VWP망 내부로 직접적인 실행(Execute) 코드나 요청이 넘어가지 않도록, 오피스망 내부의 `Docker`가 VWP망의 `S3 Server`를 통해 객체 단위로 파일을 Read-Only(읽기 전용) 형태로 끌어오는 구조를 구현했습니다.
3. **방법론 3: VWP망 내재화 (완전 격리형)**
   - 방화벽(망 연동)을 타면서 발생하는 지연(Latency) 문제를 원천 차단하기 위해, 오피스망을 전혀 사용하지 않고 VWP망 내부에 `LLM`, `Docker`를 모두 구성하는 다이어그램을 구현했습니다.
4. **결론: 테스트 방향성 제시**
   - 응답 속도(Latency), 보안성(Isolation), AI 추론 품질이라는 세 가지 항목을 나열하여 3가지 아키텍처 중 최적을 가려내는 향후 과제를 제시했습니다.
