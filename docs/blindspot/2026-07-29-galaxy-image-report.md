## Human 섹션

### 요약

**1. 실사 은하수 이미지 적용**
이전까지 수백 개의 작은 원형 입자로 캔버스에 그렸던 파티클 형태의 배경을 모두 없애고, 사실적이고 웅장한 하나의 은하수(Galaxy) 이미지로 교체했습니다.

**2. 자연스러운 무한 자전**
이미지가 단순히 멈춰있지 않고 중앙을 축으로 천천히 회전(`rotate`)하도록 애니메이션을 추가했습니다.
이때 이미지가 화면을 가득 채우면서도 네모난 모서리가 보이지 않도록 화면 대각선 길이보다 더 크게 리사이징(`150vmax`)하고 중심에 고정시켰습니다.

### 리뷰 포인트 (개발자용)

- `assets/galaxy.jpg` 추가: 오프라인 모드나 네트워크가 없는 환경에서도 문제없이 불러올 수 있도록 로컬 에셋으로 저장했습니다.
- `scripts/galaxy.js` 완전 삭제: 더 이상 프레임 렌더링에 CPU 자원을 낭비하지 않도록 불필요해진 자바스크립트 파일을 걷어냈습니다.
- `index.html` 및 `slides/*/index.html`: 무겁던 `<canvas>` 태그를 가벼운 `<div class="galaxy-bg">`로 교체하고 관련 script 로딩 구문을 뺐습니다.
- `styles.css` 갱신: CSS 기반의 하드웨어 가속 `rotate` 애니메이션(주기 240초)을 씌웠으며, `prefers-reduced-motion`이 켜진 접근성 환경에서는 즉각 애니메이션이 정지되도록 예외 처리를 완료했습니다.

## Agent 섹션 (AI 인수인계용)

### 의도 (Intent)
사용자의 요청에 따라 배경 시각 효과의 퀄리티를 대폭 상향시킴과 동시에, 자바스크립트를 통한 CPU 렌더링을 완전히 배제하고 CSS 기반 GPU 렌더링으로 넘겨 배터리 수명 및 슬라이드 퍼포먼스를 향상시킵니다.

### 제약 (Constraints)
- `file://` 오프라인 호환성을 위해 외부에 있는 CDN이나 타사 이미지를 불러오지 않고 에셋 폴더에 복사 후 상대경로로 참조시켰습니다.
- 기존 `.galaxy-bg` 클래스명을 유지하여 하위 슬라이드 템플릿의 영향을 최소화했습니다.
