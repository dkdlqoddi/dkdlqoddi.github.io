# AI Agent Skills Philosophy 요구사항

- 날짜: 2026-08-19
- 상태: 초안
- 관련 문서: 없음

## 요청 배경

유명한 인공지능 코딩 에이전트들의 주요 기능(스킬)과 그 속에 담긴 철학을 소개하는 발표자료가 필요합니다. 텍스트를 최소화하고 시각 자료를 활용하여 각 도구의 작동 구조와 설계 사상을 쉽게 설명해야 합니다.

## Unknowns 4분면

| 분면 | 항목 |
|---|---|
| Known Knowns (명시된 요구사항) | 한 페이지에 도구 1개씩 소개. 시각 자료(시스템 흐름도) 중심. 필수 포함 대상: oh-my-opencode, superpower, grill-me, ponytail, fablize, blindspot-flow. |
| Known Unknowns (답이 필요한 질문) | Codex의 어떤 스킬을 소개할지 결정 필요. 개발, 기획, 도메인 분야의 추가 스킬 3개를 무엇으로 선정할지 결정 필요. |
| Unknown Knowns (인터뷰로 드러난 암묵적 선호) | 각 철학을 설명할 때 사용자 경험이나 추상적 가치보다는 도구가 실제로 어떻게 작동하는지를 보여주는 시스템 흐름을 선호함. |
| Unknown Unknowns (미지 영역) | 선정될 4개의 추가 스킬들에 대해 아키텍처 다이어그램을 어떻게 일관된 디자인(기존 다크 테마 및 SVG 규칙)으로 묘사할 수 있을지. |

## 확정 요구사항

1. **시각화 방식**: 모든 스킬은 텍스트보다 시스템 내부의 작동 구조와 흐름을 보여주는 아키텍처 다이어그램으로 철학을 표현합니다. (인터뷰 Q2 답변 근거)
2. **슬라이드 밀도 제한**: 너무 많은 정보를 담지 않기 위해 1페이지에 딱 1개의 스킬만 소개합니다. (사용자 최초 지시)
3. **추가 스킬 선정 규칙**: 필수 포함 6개 외에 Codex 생태계에서 1개, 그리고 개발, 기획, 도메인 확장에 특화된 유명 스킬을 각각 1개씩(총 3개) 에이전트가 자체 선정하여 추가합니다. (인터뷰 Q1 및 Q3 답변 근거)

## 인터뷰 기록

| 질문 | 답변 | 아키텍처 영향 |
|---|---|---|
| Q1. 추가로 소개할 플러그인과 에이전트는 주로 어떤 분야에 특화된 것들을 포함할까요? | 개발, 기획, 도메인 확장에 특화된 스킬들을 골고루 하나씩 섞어서 구성. | 발표자료에 추가될 3가지 슬라이드의 주제 범위(개발, 기획, 도메인)를 결정함. |
| Q2. 각 스킬의 철학을 시각 자료로 전달할 때 어떤 방식이 가장 효과적일까요? | 시스템 내부의 작동 흐름과 모듈 간 연결을 보여주는 구조도 방식. | 각 슬라이드의 SVG 다이어그램 테마가 '시스템 흐름도(아키텍처)'로 확정됨. |
| Q3. Codex 관련 소개 시 어떤 구체적인 환경이나 기능에 초점을 맞출까요? | 코덱스에서 유명한 플러그인이나 에이전트, 스킬을 임의로 선정하여 철학을 설명해 달라. | 코덱스의 작동 원리나 GitHub Copilot 등 대표 사례 1개를 에이전트가 판단하여 추가함. |

## 미해결 질문

- 자체적으로 선정해야 하는 4개의 추가 스킬(Codex 1개, 개발 1개, 기획 1개, 도메인 1개)은 구체적으로 무엇으로 할 것인가? (blindspot-pass 단계에서 구체화 필요)
