## Agent 섹션 (AI 인수인계용)

### 의도 (Intent)
단순 비교를 넘어, 발표자가 설명할 때 청중이 기존 방식의 한계와 새 방식의 확장성(자연어 이해, 맥락 유지, 자기 치유)을 한 화면에서 파악하게 한다. 기존 템플릿의 색상 체계와 오프라인 지원 규칙(상대 경로, 로컬 폰트)을 철저히 따른다.

### 제약 (Constraints)
- 플러그인이 금지된 `reveal.js` 환경이므로 CSS와 SVG만으로 구현.
- `@media print` 환경 지원을 위해 SVG 다이어그램은 `currentColor`로 처리하며 특정 색상은 클래스로 관리.
