# Work Report: AI Coding Tool 설계 자동화 발표자료 추가

## 개요
- **목표**: AI Coding Tool을 사용한 설계 자동화 파이프라인(자동 실행 -> 로그 자동 분석 -> 결과 자동 보고) 과정을 설명하는 텍스트 최소화 / SVG 시각화 기반 발표자료 추가.
- **구현 파일**: 
  - `slides/ai-coding-automation/index.html` (신규 발표자료)
  - `slides.json` (목록 등록)

## 주요 구현 사항 및 블라인드스팟 점검
1. **Dark Space HUD 테마 적용**: 초기 흰 바탕 노출을 막기 위해 `<meta name="color-scheme" content="dark">`와 `html { background: #0e0e0e; color-scheme: dark; }` 삽입 완료.
2. **오프라인/로컬 구동 보장**: Reveal.js 및 테마 폰트 자산(Pretendard)을 외부 CDN 없이 동봉된 `vendor/` 경로로 상대 참조.
3. **SVG 파이프라인 및 모핑(Auto-animate)**: 
   - 텍스트를 최소화하라는 요구사항에 맞춰 시각적 다이어그램(SVG)을 구성.
   - 툴 아이콘(톱니바퀴), 분석 엔진(돋보기), 보고서(막대그래프)를 SVG 노드로 표현.
   - `data-auto-animate`를 활용해 `<section>` 전환 시 다이어그램 노드의 크기와 밝기(`.dim` -> `.bright`)가 자동으로 자연스럽게 보간되도록 구현.
   - 로그 파일 등 세부 요소들은 `class="fragment"`로 설정해 키보드 조작에 맞춰 차례로 렌더링되게 구성.
4. **인쇄 및 접근성 방어**:
   - SVG에 `role="img"` 및 `aria-label` 속성 추가.
   - 시각장애인용 낭독기를 위해 `<p class="visually-hidden">` 구문 삽입.
   - 프린트 시 `.print-pdf` 클래스가 아닐 경우 강제로 흑백(`#000`) 렌더링을 보장하는 `@media print` 룰 이식 확인.
