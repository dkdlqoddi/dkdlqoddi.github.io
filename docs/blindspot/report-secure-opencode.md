# Work Report: VWP망 내 안전한 Opencode 활용 구조

## 1. 개요
* **목표:** VWP망 내 Docker 컨테이너에서 Opencode를 안전하게 구동하는 구조에 대한 시각 중심의 발표자료 생성
* **결과물:** `slides/secure-opencode/index.html` 생성 및 `slides.json` 등록 완료
* **특이사항:** `slides/sample/` 템플릿을 기반으로 Dark-Space 테마를 상속받았으며, 텍스트를 최소화하고 3개의 SVG 다이어그램을 삽입함.

## 2. 주요 구현 내용
1. **아키텍처 오버뷰 다이어그램:** VWP망 -> Docker -> Opencode의 중첩 격리 환경을 SVG 애니메이션(fragment)으로 구현.
2. **볼륨 마운트 전략 다이어그램:** 
   * **보호 대상:** Read-Only (RO) 마운트로 연결 (회색, 점선 활용)
   * **작업 대상:** Read-Write (RW) 마운트로 연결 (흰색, 실선 활용)
3. **실행 환경 제약 (에러 케이스) 다이어그램:** 호스트에 존재하지만 Docker에 마운트되지 않은 경로를 참조 시 발생하는 에러 시나리오 시각화.
