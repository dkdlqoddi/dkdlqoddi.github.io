# 우주 유영 테마 리디자인 설계 문서

- 날짜: 2026-07-27
- 입력: `docs/blindspot/2026-07-27-space-theme-requirements.md`, `docs/blindspot/2026-07-27-space-theme-unknowns.md`

## 목적과 배경

이 사이트는 발표 자료를 모아 두는 개인 기록 공간이다. 첫 화면에 발표 목록이 있고, 각 항목을 누르면 슬라이드 자료가 열린다. 지금은 흰 배경에 검은 글자를 쓴다. 흰 하늘에 검은 별이 떠 있는, 반전된 우주 컨셉이었다.

2026-07-30 목요일에 발표가 예정되어 있다. 발표는 기존 자료(CDS Agentic Work)를 그대로 다시 사용한다. 발표 전에 사이트 전체 분위기를 "흰색 우주선이 검은 우주를 유영하는" 모습으로 바꾼다. 참고한 사이트는 euiyun.com이다. 그 사이트에서 디자인 수치와 움직임의 질감만 가져온다. 한글 글꼴을 특히 중요하게 다룬다.

바뀌는 화면은 네 곳이다. 첫 화면(발표 목록), 기존 발표 자료, 새 발표 자료를 만들 때 복사해 쓰는 견본, 그리고 주소를 잘못 쳤을 때 나오는 404 페이지다. 이 문서에서 "발표 자료"는 기존 자료와 견본 둘 다를 가리킨다. 견본은 복사 원본이므로 표지 우주선, 별, 인쇄 규칙까지 기존 자료와 똑같이 받는다.

## 동작 방식

**첫 화면을 열면.** 방문자가 사이트에 들어오면 검은 우주가 뜬다. 흰 별 60~90개가 아주 천천히 흐른다(한 바퀴 140초 이상). 화면 가장자리에 계기판(HUD) 테두리와 좌표 문구가 희미하게 떠 있다. 흰 우주선 실루엣 하나가 제자리에서 천천히 위아래로 떠다닌다(주기 6초 이상, 이동량 8px 이하). 제목과 발표 목록이 아래에서 부드럽게 떠오른다(0.7초, 감속 곡선). 발표 카드에 마우스를 올리면 테두리가 밝아진다.

**기존 발표 자료를 열면.** 카드를 누르면 화면이 부드럽게 어두운 슬라이드로 넘어간다(0.18초 교차 전환). 견본은 목록에 없지만 표지 우주선·별·인쇄 규칙을 똑같이 물려받는다. 양쪽 다 같은 배경색이라 번쩍임이 없다. 전환 효과가 없는 브라우저에서도 head 안 선언 덕분에 처음부터 어둡다. 표지에는 제목, 부제, "2026-07-30 · 우제율", 그리고 작은 흰 우주선이 있다. 화살표 키로 슬라이드를 넘긴다. 내용 슬라이드에는 우주선 없이 별과 본문만 있다. 글자는 전부 Pretendard로 나온다.

**인터넷이 없어도.** 저장소 폴더를 통째로 복사해 발표 자료를 더블클릭으로 열어도 똑같이 동작하도록 설계한다. 발표 자료가 두 단계 위의 공용 폴더(vendor)를 참조하므로 저장소 전체가 복사 단위다. 글꼴이 CSS 안에 내장되어 있어 별도 글꼴 파일을 불러올 필요가 없다. 실제로 그렇게 동작하는지는 구현 검증 단계에서 실측한다(열린 질문: 내장 글꼴 file:// 실측).

**움직임 줄이기를 켠 사용자에게는.** 운영체제 설정을 존중해 별, 우주선, 등장 효과가 모두 정지한다. 내용은 처음부터 전부 보인다.

**인쇄하면.** 인쇄는 두 갈래다. 보통의 브라우저 인쇄(Ctrl+P, "PDF로 저장" 포함)에서는 흰 종이에 검은 글자로 나온다. 직접 만든 구조 그림도 검은 선으로 나온다. 별과 우주선은 인쇄에 나오지 않는다. 반면 주소 끝에 ?view=print를 붙이는 reveal 전용 인쇄 화면은 어두운 화면 그대로 PDF가 된다. 이 어두운 PDF는 화면 열람용으로 수용한다.

**배포는.** 작업 브랜치에서 구현하고, 머지 전 퀴즈를 통과한 뒤 main에 합치면 곧 사이트에 반영된다. 첫 화면 CSS에 버전 표식이 있어 재방문자도 옛 스타일과 섞이지 않는다.

## 의도적 범위 제외

- **밝은 테마 병행(다크/라이트 전환)** — 색 체계 두 벌의 제작·검증 비용이 크고, 사용자가 단일 어두운 테마를 선택했다.
- **euiyun.com의 입자 캔버스와 여러 색 강조** — 상시 움직이는 배경은 발표 집중을 방해하고, 강조 색은 무채색 원칙과 충돌한다.
- **라틴 전용 글꼴 추가(Inter, Space Grotesk 등)** — Pretendard의 라틴 글자가 이미 Inter 계열이라 실익 대비 용량만 늘어난다.
- **내부 문서(docs/blindspot)와 퀴즈 화면의 테마 적용** — 방문자 동선에 없는 내부 산출물이다. 링크로 연결되지도 않는다.
- **과거 blindspot 문서의 소급 수정** — 당시 결정의 이력이다. 새 문서가 대체 사실을 기록하는 것으로 충분하다.
- **4K·모바일 별 밀도 최적화** — 고정 개수로도 충분히 자연스럽다. 화면 크기별 분기는 유지 비용만 늘린다.
- **동봉 테마(black.css) 안의 안 쓰는 내장 글꼴 정리** — 테마 파일은 버전 고정·무수정이 규칙이다. 죽은 570KB를 수용한다.
- **첫 화면 목록 스크립트의 기능 변경(빈 목록 표시 등)** — 테마와 무관한 동작이다. 이번 작업은 시각만 바꾼다.
- **새 발표 자료 제작** — 2026-07-30 발표는 기존 자료를 재사용한다.
- **소셜 미리보기 이미지(og:image)** — 원래 없던 요소다. 이번 범위에 넣으면 이미지 파일 없음 관례와도 충돌한다.

## 열린 질문

| 질문 | 해소 계획 |
|---|---|
| 내장 글꼴이 인터넷 없이(파일 더블클릭) 실제로 뜨는가? | 구현 검증 단계에서 Chrome과 Firefox로 file:// 실측한다. 담당: 구현자. |
| 단어 단위 줄바꿈 적용 후 기존 20장에서 글이 넘치는 곳이 없는가? | 구현 검증 단계에서 전 슬라이드를 스크린샷으로 확인한다. 담당: 구현자. |
| 발표 당일 회의실 프로젝터에서 어두운 화면이 충분히 보이는가? | 발표 전 실제 장비로 리허설한다. 조명을 낮출 수 있는지 확인한다. 담당: 발표자(우제율), 2026-07-30 이전. |
