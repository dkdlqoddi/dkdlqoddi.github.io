# '나만의 돌쇠 AI 만들기' 전 슬라이드 노스크롤(No-Scroll) 최적화 요구사항 정의서

- 문서 ID: 2026-09-01-my-dolsoe-ai-no-scroll-requirements
- 대상: `slides/my-dolsoe-ai/index.html` (20개 슬라이드 전체)
- 날짜: 2026-09-01

## 1. 배경 및 문제 정의
현재 `my-dolsoe-ai` 슬라이드 중 일부에서 코드 블록, 설명 카드, 마진/패딩의 누적으로 인해 기본 뷰포트(960×700) 높이를 초과하여 세로 스크롤바가 발생하거나 내용이 잘리는 현상이 확인되었습니다. 발표용 reveal.js 데크는 모든 슬라이드가 스크롤 없이 한 화면에 완결성 있게 표출되어야 합니다.

## 2. 세부 요구사항

### 2.1 전 슬라이드 높이 예산 관리 (EVA VIEW 700px 이내 완결)
- 상단 HUD 및 3D 은하 배경과 겹침 없이 모든 콘텐츠가 캔버스 내부(안전 영역 높이 ≤ 620px)에 위치.
- 상하 마진 및 타이포그래피 위계 정밀 조정:
  - `eyebrow`, `h2`, `h3`, `p.small`의 상하 마진 축소 (`margin: 0 0 6~10px`).
  - 제목 폰트 크기 및 줄간격 최적화 (`line-height: 1.15~1.25`).
- 2열 레이아웃(`cols-2`) 및 카드 패널(`panel-card`) 최적화:
  - 코드 블록 폰트 크기(`font-size: 0.50~0.54em`) 및 패딩(`padding: 0.5em 0.8em`) 축소로 12~16줄 코드도 240~280px 이내 표시.
  - 우측 카드 패널 패딩(`padding: 8px 12px`) 및 카드 간격(`margin-bottom: 6px`) 축소.
- 그리드 슬라이드(Slide 2, 7, 15, 16, 20) 재배치:
  - 4~7개 카드가 포함된 슬라이드는 컴팩트한 다단 그리드(2열 또는 3열)로 재구성하여 전체 높이 380px 이내 유지.
- SVG 다이어그램(Slide 4~6, 8, 9, 12~14) 비율 조정:
  - Slide 14 전체 지도 SVG의 `viewBox`를 `0 0 900 270` 수준으로 슬림화하고 여백 최적화.

### 2.2 비기능 요구사항
- 템플릿 코드 복사 버튼(`code-copy.js/css`) 동작 완벽 유지.
- 0개 CDN 외부 의존성 유지.
- 인쇄(`@media print`) 및 모션 축소(`prefers-reduced-motion`) 안전 규칙 100% 준수.
- 20개 슬라이드의 텍스트, 코드, 비유 체계의 내용 누락 0건.
