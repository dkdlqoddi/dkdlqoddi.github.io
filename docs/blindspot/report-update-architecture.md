# Work Report: 발표자료 내용 재편 및 아키텍처 대조 기획

## 1. 개요
* **목표:** 2번 발표자료("안전한 AI 설계 자동화 아키텍처")의 내용을 전면 개편하여, "똑똑한 유료 모델 vs 멍청한 사내 오픈소스 모델"의 **구조적 차이점**에 초점을 맞추도록 작성.
* **해결 내용:** 
  1. 1번 발표자료와 중복되었던 단순 개념 설명(Hallucination 한계 등) 슬라이드를 모두 삭제.
  2. 단순한 API 구조로 쉽게 사용할 수 있는 스마트 상용 모델 구조(비교군) 추가.
  3. 자의적이고 오작동이 잦은 오픈소스 모델을 통제하기 위해 VWP망 내에 3중 방어선(Harness, 망 연동 방화벽, Docker 샌드박스)을 구축한 아키텍처 슬라이드로 전면 교체.

## 2. 세부 변경 사항
* `integrated-architecture/index.html` 파일 내부 텍스트 및 다이어그램(SVG)을 새 기획안에 맞춰 전부 재작성했습니다.
* **1차 방어:** Harness의 JSON 스키마 검증 및 자동 재시도 루프 강조
* **2차 방어:** VWP망 망분리와 페이로드 압축으로 컨텍스트 오버플로우 방지 
* **3차 방어:** VWP Host 디렉토리를 보호하기 위한 컨테이너 Read-Only 마운트 강조
