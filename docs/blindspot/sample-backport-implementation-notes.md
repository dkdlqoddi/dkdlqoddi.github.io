## 2026-07-28 — kbd 크기 수정 방식

- 결정: `.kbd`의 `font-size: 0.7em`을 삭제해 주변 글자 크기를 그대로 물려받게 한다.
- 이유: `.small`(0.6em) 안에서 0.7em이 중첩 곱해져 17.6px까지 떨어졌다. 상속이면 25.2px로 하한(24px)을 넘고, 잎에서 한 번만 지정하는 원칙과도 맞는다.
- 검토한 대안: 0.58em 고정 — `.small` 밖에서 쓰면 문제없지만 안에서 쓰면 또 중첩 곱이 생겨 기각.
- 보수적 선택 여부: 예 (삭제가 최소 수정)
- 계획과의 이탈: 없음
- 사용자 확인 필요: 아니오

## 2026-07-28 — 데모 그림 구성 확정

- 결정: 데모 1장은 "1 복사, 2 수정, 3 등록" 세 상자를 단계 공개 2회로 보여준다. 데모 2장은 모핑으로 세 상자가 왼쪽으로 좁혀지고 "4 공개" 상자가 자동 페이드로 더해진다. 짝 없는 요소의 자동 페이드는 일부러 남겨 그 동작 자체를 시연한다.
- 이유: 요구사항 자체 해소 항목(데모 소재 = 덱이 가르치는 절차)의 구체화다. 자동 페이드 억제 속성(`data-auto-animate-unmatched="false"`)은 주석으로만 안내한다 — 데모에서는 억제하지 않는 쪽이 기본 동작을 보여준다.
- 검토한 대안: cds 덱 3~5장 축소 복제 — 발표 서사(망 분리)가 견본 맥락과 무관해 기각.
- 보수적 선택 여부: 아니오
- 계획과의 이탈: 없음
- 사용자 확인 필요: 아니오
