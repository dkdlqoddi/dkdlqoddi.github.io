# 폰트 렌더링 개선 요구사항

- 날짜: 2026-07-28
- 상태: 초안
- 관련 문서: 없음

## 요청 배경

사용자가 전체 슬라이드 화면에서 한글 글씨가 흐릿하고 뭉개져 보이는 현상을 해결해 달라고 요청했습니다. 이를 위해 다른 프로젝트의 화면 처리 기술을 참고하라는 언급이 포함되었습니다.

## Unknowns 4분면

| 분면 | 항목 |
|---|---|
| Known Knowns (명시된 요구사항) | 슬라이드 내 한글 흐릿함 문제 해결, 다른 프로젝트 참고 |
| Known Unknowns (답이 필요한 질문) | 기술 적용 범위를 기존 자료까지 소급할 것인지 결정 |
| Unknown Knowns (인터뷰로 드러난 암묵적 선호) | 기존 발표자료 파일과 새 템플릿 파일 양쪽 모두에 일괄 적용을 원함 |
| Unknown Unknowns (미지 영역 — blindspot-pass 대상) | 모든 슬라이드 파일을 일괄 수정할 때 발생할 수 있는 문서 깨짐 부작용 여부 |

## 확정 요구사항

1. 모든 기존 슬라이드 데크 파일과 템플릿 파일 내부 코드에 화면 글씨 다듬기 기술(안티앨리어싱)을 일괄적으로 추가합니다. (근거: "만들어둔 모든 발표자료 파일과 새 템플릿 양쪽 모두에 일괄 적용" 답변)

## 인터뷰 기록

| 질문 | 답변 | 아키텍처 영향 |
|---|---|---|
| 화면 글씨 처리 기술을 모든 슬라이드 파일에 일괄 추가할 것인지 아니면 새 템플릿에만 우선 적용할 것인지 선택 | 기존 모든 파일과 새 템플릿 파일 양쪽에 일괄 적용 | 단일 템플릿 수정 작업에서 다수 파일 일괄 수정 작업으로 영향 범위가 크게 확장됨 |

## 미해결 질문

- 여러 파일을 한 번에 수정할 때 예기치 않게 코드가 깨지거나 변경이 누락되는 안전성 문제는 없는가? (blindspot-pass 단계에서 점검)
