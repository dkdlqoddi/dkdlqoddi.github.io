# Requirements Interview: Architecture Slide Revisions & Animation

피드백해주신 내용(API Server의 위치 변경, 대문자 최소화, 한글 제약사항 번역, 글씨 크기 조정)을 완벽하게 반영하겠습니다. 아울러 요청하신 "프롬프트 입력 및 통신 이동 전체 애니메이션 슬라이드" 추가와 관련하여 최상의 시각 효과를 내기 위해 몇 가지 디자인 결정을 먼저 확정하고자 합니다.

### 인터뷰 질문 (구현 방향 확정)

**1. 통신 이동 애니메이션의 시각적 표현 방식**
사용자 프롬프트가 각 노드를 거쳐 이동하는 과정을 SVG로 구현할 때 어떤 스타일이 우주선 테마에 더 어울릴까요?
- **[A] 광자 펄스(Data Pulse) 스타일**: 빛나는 작은 점(또는 빛줄기)이 선을 따라 각 노드로 쏘아지듯 빠르게 이동하는 시각 효과 (가장 사이버틱함, 권장)
- **[B] 패킷 블록(Packet Block) 스타일**: "Prompt", "JSON", "Data" 같은 작은 텍스트 박스가 선 위를 천천히 미끄러져 이동하는 직관적인 효과

**2. 애니메이션 실행 타이밍 (Reveal.js 연동)**
새로 추가되는 애니메이션 슬라이드는 언제 동작을 시작하는 것이 발표 흐름에 좋을까요?
- **[A] 슬라이드 진입 시 자동 재생 무한 루프**: 발표자가 해당 슬라이드로 넘어오자마자 알아서 통신 과정이 계속 반복 재생됨 (발표에 집중하기 좋음)
- **[B] 단계별 클릭(Fragment) 실행**: 발표자가 키보드(또는 리모컨)를 넘길 때마다 [입력] -> [Harness 통과] -> [API 전달] 등 통신이 1단계씩 끊어서 진행됨

**3. API Server 위치 변경에 따른 UI 밸런스**
API Server를 오피스망(좌측)으로 옮기면, VWP망(우측)에는 MCP Server 노드 1개만 남게 됩니다.
- **[A] 우측 여백 활용**: MCP 서버 크기를 약간 키워 강조하고 밸런스를 맞춤
- **[B] 방화벽 위치 이동**: 방화벽 렌더링 선을 우측으로 치우치게 그려 전체적인 좌우 균형(1:1 비율)을 유지함
