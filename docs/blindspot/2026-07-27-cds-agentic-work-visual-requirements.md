## 요청 배경

2026-07-30 발표용 덱(발표 화면 묶음)인 `slides/cds-agentic-work/`에 글이 너무 많다는 요청이 들어왔다. 현재 덱은 모두 20장이다. 전체 글자 수는 3,235자이고, 글이 가장 많은 장은 221자다. 잘 만든 발표 자료 저장소의 표현 방식을 참고해, 글을 줄이고 눈에 보이는 자료와 애니메이션으로 채우는 것이 목표다.

## 확정 요구사항

1. 발표 내용(이야기 흐름, 다루는 주제, 장 순서)은 현재 덱 그대로 유지한다. 다른 발표 자료 저장소는 표현 방식만 참고한다. (답변: "발표 repo = 스타일 참고")
2. 사진·비트맵 그림 파일 추가 금지 규칙을 유지한다. 시각 자료는 인라인 SVG(코드로 그린 그림)와 CSS 도형으로만 만든다. (답변: "규칙 유지")
3. 애니메이션은 등장 모션과 단계 공개까지만 허용한다. fragment(한 장 안에서 요소를 순서대로 보여주는 기능)와 auto-animate(장을 넘길 때 같은 도형이 변형되는 기능)는 등장 모션으로 간주한다. 발표 중 계속 반복되는 움직임은 넣지 않는다. (답변: "등장 + 단계 공개까지")
4. 장 수는 20장 안팎을 유지한다. 모핑(auto-animate로 도형이 변형되는 표현)이 꼭 필요한 곳에만 장을 1~2장 더해, 전체 25장을 넘지 않는다. (답변: "20장 안팎 유지")
5. 모션 최소화 설정 사용자에게 모든 애니메이션이 자동 정지되는 기존 차단 규칙은 그대로 유지한다.
6. space theme 확정 요구사항은 전부 승계한다. 구체적으로 무채색 팔레트, 어둠 선언(화면이 처음부터 검게 열리도록 미리 지정하는 것), 인쇄 안전, 접근성 규칙이다.

### 자체 해소 항목 (질문하지 않고 근거로 결정)

- 텍스트를 줄여 생긴 공간은 우선 글자 크기 상향에 쓴다. 현재 본문은 기본 크기의 0.42~0.62배까지 줄어 있다. 구현 노트에는 "발표장 뒷자리에서 안 보인다"는 우려가 기록되어 있다. 남는 공간은 다이어그램 여백에 쓴다.
- 단계 공개는 발표 도구(reveal.js)에 내장된 fragment 기능으로 구현한다. 일반 인쇄(Ctrl+P)에서는 도구가 모든 요소를 강제로 보이게 해 준다. 전용 인쇄 주소(`?view=print`)에서는 단계마다 쪽이 늘어나는 문제가 있다. 그래서 단계별 쪽 나눔을 끄는 설정을 추가한다. (2026-07-27 blindspot-pass에서 보완)
- 슬라이드에서 지운 글은 별도 유인물로 만들지 않는다. 전체 내용이 이미 [explainer 문서](2026-07-23-cds-agentic-work-explainer.md)의 장별 구성에 남아 있다.

## 미해결 질문

- 스타일 참고 기준으로 삼을 발표 저장소 후보를 아직 정하지 않았다. blindspot-pass에서 조사한다.
- 20장 각각을 어떤 시각 유형(다이어그램, 단계 공개, 모핑, 글자 유지)으로 바꿀지 장별 매핑이 없다. 설계 단계에서 정한다.
- auto-animate가 기존 모션 차단 규칙(모든 전환 시간을 0.01ms로 강제)과 충돌하는지 확인이 필요하다.
- fragment가 늘어나면 발표 중 조작 횟수와 인쇄 페이지 수가 늘어난다. 허용 수준을 설계 단계에서 정한다.
- 청중의 사전 지식 수준은 최초 제작 때부터 미확인으로 남아 있다. 이번 개편에서는 기존 설명 깊이를 그대로 유지한다.
- 새 CSS 도형의 인쇄 되돌림 규칙을 지금처럼 하나씩 열거할지, 포괄 규칙으로 바꿀지 구현 시 정한다.
