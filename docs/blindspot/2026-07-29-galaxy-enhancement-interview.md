# Requirements Interview: Landing Page Scroll Lock & 3D Galaxy Enhancement

말씀하신 피드백(랜딩 페이지 스크롤 금지 및 우주 요소 고도화)을 확인했습니다. 현재 Three.js 캔버스 기반으로 렌더링 중인 은하계에 별의 크기/밝기 변주, 혜성(Comet), 성운(Milky Way) 등을 추가하기 위해, 아래 3가지 디자인 옵션을 먼저 결정해 주시면 감사하겠습니다.

### 인터뷰 질문 (구현 방향 확정)

**1. 랜딩 페이지 스크롤 금지(Scroll Lock) 방식**
스크롤을 막는 것은 3D 카메라 뷰에 집중시키기 위함입니다. 어떤 방식이 좋을까요?
- **[A] 완전 차단 (권장)**: CSS `overflow: hidden`을 통해 스크롤바 자체를 없애고, 마우스 휠 및 터치 스크롤 이벤트를 완전히 막아 3D 공간 제어만 가능하게 만듭니다.
- **[B] 탄성(Bounce) 유지**: 스크롤바는 숨기지만 모바일의 스와이프 탄성(끝에서 튕기는 효과)은 미세하게 남겨두어 네이티브 앱 같은 느낌을 줍니다.

**2. 우주 요소(혜성, 항성) 렌더링 기법**
오프라인 환경 및 외부 리소스(이미지 파일) 금지 원칙을 준수하기 위해 어떤 방식을 취할까요?
- **[A] 순수 절차적 렌더링 (Procedural, 권장)**: 외부 이미지 없이 오직 Three.js의 `BufferGeometry`와 `Math.random()`, 커스텀 셰이더(Shader) 수식만을 활용해 거대 항성의 크기 변주와 혜성의 꼬리 궤적을 렌더링합니다.
- **[B] 텍스처 삽입 (Base64 인코딩)**: 혜성이나 성운의 리얼리티를 높이기 위해 외부 PNG 텍스처를 썼으나 네트워크 금지 룰에 따라 Base64 문자열로 스크립트 안에 하드코딩하여 집어넣습니다. (파일 용량 커짐)

**3. 은하수(Milky Way) 및 성운 묘사 방식**
어떤 방식으로 은하수 먼지 구름을 표현할까요?
- **[A] 볼류메트릭 파티클 구름 (권장)**: 기존 나선팔을 따라 투명도(Opacity)가 높고 크기가 거대한 파티클들을 수만 개 더 흩뿌려, 빛나는 우주 먼지 구름처럼 보이게 만듭니다.
- **[B] 2D 백그라운드 노이즈**: 은하계 뒤편(배경)에 정적인 2D 캔버스 노이즈(Perlin Noise)를 깔아서 우주 배경처럼 보이게 만듭니다.
