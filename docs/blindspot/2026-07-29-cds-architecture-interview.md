# Requirements Interview: CDS Agentic Architecture Presentation

새로운 "CDS Agentic Architecture" 발표 자료 구성 및 기존 자료 삭제 요청을 분석했습니다. 요청하신 제약 조건(오피스망-VWP망 방화벽 분리, 성능이 낮은 CodeMate LLM, 안전장치 등)을 기반으로 다음과 같은 3가지 주요 아키텍처 문제점(Limitations)을 도출했습니다.

### 도출된 주요 문제점 (Inferred Problems)
1. **Agentic Loop 지연(Latency) 문제**: CodeMate LLM 자체가 느린 데다, 하나의 목표를 위해 여러 번 툴을 호출하는 에이전트 특성상, [LLM ↔ Harness ↔ 방화벽 ↔ API ↔ MCP]를 오가는 왕복(Round-trip) 횟수가 곱해져 치명적인 속도 저하가 발생할 수 있습니다.
2. **모델 할루시네이션(환각)과 Harness의 과부하**: 사외 상용 모델 대비 부족한 추론 성능으로 인해 존재하지 않는 툴을 호출하거나 JSON 형식을 파괴하는 빈도가 높습니다. 이로 인해 Harness가 잘못된 요청을 방화벽 밖으로 나가기 전에 차단하고 교정(재시도)해야 하므로 Harness 로직이 극도로 복잡해집니다.
3. **컨텍스트 창(Context Window) 한계 및 데이터 병목**: VWP망의 방대한 로그나 파일 데이터를 MCP가 반환할 때, API 서버와 방화벽을 거쳐 성능이 낮은 LLM에게 그대로 주입하면 모델이 지시사항을 망각하거나 컨텍스트 한계에 부딪혀 고장날 위험이 큽니다.
