## 2026-07-23 18:35 — 랜딩 시각 설계 세부 확정

- 결정: ① 시그니처는 화면을 감싸는 고정 헤어라인 프레임(HUD)+모서리 계기 문구, ② 별 입자는 "흰 하늘에 검은 점" 반전 표현(2겹, 초저속 부유), ③ 완전 모노크롬(악센트 색 0개), ④ 계기 문구는 시스템 모노스페이스 폰트(추가 로딩 0), ⑤ 카드의 LOG 번호는 시간순 발표 순번(표시는 최신순), ⑥ Pretendard v1.3.9 dynamic subset을 jsDelivr 버전 고정으로 로드.
- 이유: 사용자가 고른 "미세 입자+계기판" 방향의 구체화. 통상의 검은 우주 배경을 뒤집은 흰 우주가 "흰 우주복" 브리프와 정확히 일치하고 기성 템플릿과 구분됨. 순번은 실제 기록 순서라는 정보를 담음(장식 아님).
- 검토한 대안: 악센트 1색(관제 오렌지/그린) — 흰+검 브리프의 절제를 깨서 기각. 모노스페이스 웹폰트 추가 — 용량·의존성 대비 이득 없어 기각. canvas 별 — 설계 문서에서 이미 기각.
- 보수적 선택 여부: 예 (그레인/노이즈 텍스처는 성능 비용 대비 효과 불확실로 미적용, 필요 시 추후)

## 2026-07-23 18:36 — 404 페이지는 독립형(스타일 내장)으로

- 결정: 404.html은 styles.css를 참조하지 않고 자체 스타일을 내장한다.
- 이유: 404는 임의 깊이의 주소에서 뜨므로 상대 경로가 깨질 수 있고, 절대 경로 의존도 없애면 어떤 상황에서도 렌더링이 보장된다.
- 검토한 대안: /styles.css 절대 경로 참조 — 결합도만 늘고 이득 없어 기각.
- 보수적 선택 여부: 아니오
- 계획과의 이탈: 없음
- 사용자 확인 필요: 아니오

## 2026-07-23 18:37 — 데크 경로는 상대 경로, 페이지 전환은 양쪽 opt-in

- 이유: 상대 경로는 GitHub Pages·로컬 서버·file:// 더블클릭(오프라인 발표) 세 환경 모두에서 동작한다. View Transitions는 양쪽 문서가 opt-in해야 전환이 걸린다.
- 검토한 대안: /vendor/ 절대 경로 — file:// 오프라인 시나리오가 깨져 기각.
