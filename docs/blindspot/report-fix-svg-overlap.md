# Work Report: Timeout 다이어그램 시각 오류 (겹침) 수정

## 1. 개요
* **목표:** `integrated-architecture/#/6` 슬라이드(사내 LLM API 제한)에서 "Error Badge(에러 상자)"와 "Gauge(게이지 바)"가 물리적으로 겹쳐서 글씨가 가려지는 UI 렌더링 버그 수정.

## 2. 원인 분석 및 해결 과정
1. **버그 원인 (Root Cause)**
   - SVG 좌표계 상에서 게이지 호(Arc)의 꼭대기 지점(y=50)과 에러를 표시하는 붉은색 상자의 영역(y=50~90)이 동일한 세로 좌표를 점유하고 있었습니다.
   - 이로 인해 상자가 게이지 바의 중심(Needle)과 글씨 위를 덮어버리면서 가독성이 심각하게 훼손되었습니다.

2. **복구 조치 (Hotfix)**
   - SVG 캔버스의 전체 높이(viewBox height)를 `250`에서 `350`으로 넉넉하게 늘려 공간을 확보했습니다.
   - 상단에 있던 **에러 상자를 위쪽(y=20)**으로 끌어올리고, **게이지 배경과 바늘 전체를 아래쪽(y=260)**으로 크게 밀어내어(Shift Down) 두 그래픽 요소 간에 완벽한 여백(약 50px)을 확보했습니다.
   - 이제 글씨가 겹치지 않고 100 RPM 제한과 Timeout 상황이 훨씬 선명하게 보입니다.

## 3. Pre-Merge Quiz (확인 퀴즈)
> 작업 내용 검증 및 브랜치 최종 반영(Merge)을 위해 아래 퀴즈의 정답을 채팅으로 말씀해 주세요!

**Q1. 에러 상자와 게이지 바가 서로 겹치는 현상을 해결하기 위해 SVG 캔버스(viewBox)의 무엇을 늘렸습니까?**
1. 캔버스의 너비(Width)를 900에서 1200으로 늘림
2. 캔버스의 높이(Height)를 250에서 350으로 늘림
3. 에러 상자의 투명도(Opacity)를 0으로 늘림

**Q2. 두 그래픽 요소가 겹치지 않도록 조치한 방향으로 올바른 것은 무엇입니까?**
1. 에러 상자는 위로, 게이지 바는 아래로 이동시킴
2. 에러 상자는 아래로, 게이지 바는 위로 이동시킴
3. 두 요소 모두 왼쪽으로 이동시킴
