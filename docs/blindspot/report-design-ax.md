# Work Report: 설계 AX 전환 발표자료

## 1. 개요
* **목표:** '설계 AX 전환'을 주제로, 상용 모델과 오픈소스 모델의 경험 차이를 조명하고 프롬프트 엔지니어링이 Harness 엔지니어링으로 진화하는 과정을 시각화한 발표자료 제작.
* **결과물:** `slides/design-ax-transition/index.html` 생성 및 `slides.json` 상단 등록 완료.
* **특이사항:** 텍스트를 최소화하고, 모든 주요 개념을 SVG 기반의 3단계 흐름(체급 비교 -> 프롬프트 주입 -> 하네스 구조화) 다이어그램으로 애니메이션화하여 전달력을 극대화함.

## 2. 주요 시각화 구성 내용
1. **모델 체급별 경험 차이 다이어그램:** 
   * "이거 해줘"라는 동일한 지시에 대해 상용 모델은 '완벽한 결과'를 내놓지만, 오픈소스 모델은 '맥락 상실 및 오동작'을 일으키는 상반된 경험을 대조.
2. **프롬프트 엔지니어링 다이어그램:** 
   * 모호한 명령에 '세부 지침(제약 조건)'과 '동작 예시(Few-shot)'를 더해 정교한 프롬프트로 묶어(Wrapping) 모델을 올바르게 제어하는 과정 시각화.
3. **Harness 엔지니어링 다이어그램:** 
   * Agentic AI 시대에 맞춰 텍스트 프롬프트가 System Rules, Tools, Guardrails라는 3가지 시스템 규격으로 형식화되어 모델을 완전히 감싸는 'Harness(안전 구속구)' 구조로 진화했음을 입체적으로 표현.
