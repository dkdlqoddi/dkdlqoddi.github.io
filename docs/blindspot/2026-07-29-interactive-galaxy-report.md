# Work Report & Pre-Merge Quiz: Interactive Galaxy HUD

- 날짜: 2026-07-29
- 상태: 카메라 시점 제어, 다색상 은하, 행성 HUD 타겟팅, 호버 줌 구현 완료

## 작업 요약 (Implementation Summary)
1. **마우스 패럴랙스 (Parallax) 시점 제어**: 추가 라이브러리 설치(OrbitControls) 없이 순수 삼각함수를 활용해, 마우스 커서의 위치에 따라 카메라 위치가 부드럽게 공전(Lerp)하도록 구현했습니다. 
2. **다채로운 색상(Multicolor)**: `scripts/galaxy3d.js` 내 파티클 색상 생성 공식을 수정하여 딥 블루, 시안, 보라색이 섞인 고급스러운 우주를 연출했습니다.
3. **타겟팅 라인(SVG HUD)**: `styles.css`를 수정해 발표 카드를 우측 사이드바로 몰아넣고, 3D 화면 속 행성의 2D 투영 좌표(Projection)에서 우측 버튼까지 이어지는 얇고 빛나는 홀로그램 선(`<line>`)과 원(`<circle>`)을 실시간 렌더링 루프에 추가했습니다.
4. **마우스 호버 시 3D 행성 줌(Zoom)**: 카드에 마우스를 올렸을 때(`mouseenter`), 연동된 3D `THREE.Mesh` 구체의 `scale`을 서서히 키워 해당 행성이 강조되도록 만들었습니다.

## Pre-Merge Quiz (Blindspot Check)

아래 퀴즈의 정답을 골라주시면 즉시 깃 커밋(Commit) 프로세스를 진행합니다!

**Q. 발표 자료(버튼)에 마우스를 올렸을 때(Hover), 배경 속 3D 은하수의 특정 행성을 어떻게 화면에서 눈에 띄게 키울 수 있었을까요?**
1) 마우스를 올리면 화면 전체를 캡처한 뒤, 이미지 자체를 돋보기처럼 확대하는 CSS `transform: scale()`을 사용했다.
2) 마우스를 올리면 3D 카메라(Camera)가 해당 행성 코앞까지 빛의 속도로 순식간에 이동해서 가깝게 찍는다.
3) 자바스크립트가 카드 호버 이벤트를 감지하면, 은하수 루프 안에서 해당 카드의 타겟이 되는 '독립된 3D 구체(Sphere Mesh)'의 크기(Scale) 속성을 3.5배로 부드럽게 키워 렌더링한다.
