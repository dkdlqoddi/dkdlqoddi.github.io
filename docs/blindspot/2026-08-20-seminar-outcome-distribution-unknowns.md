## 스캔 원본 요약

### conventions

✗/✓는 `<text>` 단일 글리프가 정본(dx:320-337), dominant-baseline 선례 0건(세로 정렬은 y 수동 오프셋 ≈ +0.36×font-size). Montserrat에 ✗·✓·● 글리프 없음, Pretendard에 U+2717/U+2713/U+25CF 있음(U+2715/2716/2718/2B24는 없어 금지). 점 r은 그림 밀도별 4단계(모프1·2=7, 모프3=4, 정리=5, 브리지=6), 색은 부모 g 일괄과 개별 class 두 선례. 스킬 구조 장 5개는 h2→tool-tags→visually-hidden→svg.diag(width 92%, 높이는 viewBox 종횡비)→summary-box 골격 동일, 한 장 SVG 2개 선례 0건, mini-diag(width 80%)가 deck-base:89에 기성 존재. 2부 fragment는 인덱스 없는 그룹 관용구, [→ n]=고유 인덱스 수 규약 전수 대조 확인. 대비 라벨 "적용 전/후" 선례 0건(기존: 잘된/망한 결과, 하네스 없을 때의 폭). SVG 라벨 크기 등급: 캡션 13/본문 15/상자 제목 16-17/축 라벨 18. 은하 위 글자는 rect 배경판(rx 5, 높이 21-22) 관용구. grill 전수 4곳 확정(philosophy:414,426,428 + script:97), 잔존 0건.

### edge-cases

짝 키 nodeName:::data-id + unmatched="false"(끊기면 페이드 없이 튐) — vendor 소스 확정. 좌표 속성 비보간, 위치는 bbox transform만 — 폴리곤 점 수 제약 없음, deck-base:95(transform-box:fill-box)가 SVG 모프 생명줄. text 짝은 font-size 이중 축소 함정(세 장 고정 필요). 요구 5·6이 현 좌표에서 기하 충돌(d5 경계, d11 2장에서 기준선 위, 모프3 전 점 상단 리본, 정리 장 전부 아래) — 재좌표로 해소, 판정 우선 원칙 확립. ✗ 글리프 Montserrat 부재(Pretendard 의존, 1부 선례로 기수용 위험). circle[fill="none"] 자동 배경판 오폭. blindspot-flow 높이 병목(레버 소진: summary-box 0.62em까지 축소 이력), 초과 시 인쇄 쪽수 증가 + 세로 중앙 정렬 해제. pdfSeparateFragments:false라 fragment는 쪽수 무관. 브리지 점선 띠 상승 시 라벨 백드롭(y106-142) 충돌, fragment 그룹에 transform 금지(인쇄 강제 해제). "남은" 오폭 후보 1건(integrated-architecture:452, leftover 의미) — 슬라이드 범위 밖 치환 금지. 모프 장 p 텍스트 완전일치 매처 — 새 문구 중복 배치 금지.
