# Requirements Interview: Landing Page Return & Takeoff Animation

말씀하신 마지막 페이지 추가 기능(랜딩 페이지 복귀 버튼, 감사 인사, 행성 이륙 애니메이션)에 대한 구현 방향을 확정하기 위해 3가지 세부 옵션을 여쭤봅니다.

### 인터뷰 질문 (구현 방향 확정)

**1. "랜딩 페이지로 돌아가기" 버튼 위치 및 스타일**
복귀 버튼을 어떻게 배치하는 것이 가장 직관적일까요?
- **[A] 중앙 집중형 (권장)**: "Thank You" 텍스트 바로 아래에 커다란 HUD 스타일의 Glowing 버튼으로 배치하여 클릭을 유도.
- **[B] 플로팅 형태**: 슬라이드 우측 하단에 고정된 작은 아이콘 형태로 띄워두기.

**2. 우주선 이륙 애니메이션 구현 방식**
현재 오프라인 SVG/CSS 규약을 준수하면서 행성(랜딩 페이지 행성 색상인 Cyan/Teal 적용)과 우주선을 어떻게 묘사할까요?
- **[A] 순수 CSS/SVG 애니메이션 (권장)**: 하단에 행성의 호(Arc)를 크게 그리고, 그 위에서 작은 SVG 우주선이 불꽃(CSS 궤적)을 뿜으며 위로 날아가는 직관적이고 가벼운 애니메이션.
- **[B] HTML Canvas 방식**: 복잡한 입자(Particle) 효과를 써서 우주선이 발사되는 모습을 세밀하게 구현 (연산량이 좀 더 높음).

**3. "Thank You" 메시지 렌더링 스타일**
감사 인사는 어떤 톤앤매너로 띄울까요?
- **[A] 네온 타이포그래피 (권장)**: 다른 제목들과 통일감 있게 `THANK YOU` 글자가 크고 밝게 빛나는(Neon Glow) 스타일.
- **[B] 타자 치는 효과 (Typewriter)**: "Presentation Complete. 시스템을 종료합니다. 감사합니다." 처럼 콘솔에 글씨가 한 줄씩 타이핑되는 효과.
