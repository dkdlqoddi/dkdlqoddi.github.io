# Work Report: 행성 셰이더 및 가독성 개선

## 1. 개요
* **목표:** 랜딩 페이지 카드에 마우스를 올렸을 때 나타나는 3D 행성의 리얼리티 강화 및 어두운 배경에서 발생하는 텍스트 가독성 문제 해결
* **결과물:** `scripts/galaxy3d.js` 셰이더 코드 수정 및 `styles.css` 호버 속성 보완

## 2. 주요 변경 사항
1. **WebGL 3D 행성 셰이더 개선 (`galaxy3d.js`)**
   * 기존의 단순한 청록색 믹스(Mix) 대신, 광원 벡터(`lightDir = normalize(vec3(1.0, 1.0, 1.0))`)와 노말 벡터를 내적(`dot`)하여 난반사(Diffuse) 조명 효과를 추가.
   * `fbm` 노이즈 값의 임계값에 따라 깊은 바다, 얕은 바다, 평야, 산맥 등 지구형 행성에 걸맞은 색상을 매핑하여 입체감을 부여.
   * 마우스를 올리고 있는 동안 행성 자체가 자전(`rotation.y += 0.01`)하도록 애니메이션 보완.
2. **텍스트 가독성 오버라이드 (`styles.css`)**
   * `.card:hover` 상태일 때 `.mono` 등 명시적인 색상이 지정되어 있던 하위 요소들의 텍스트가 어둡게 보이는 문제를 해결하기 위해, 카드 내부 모든 요소(`*`)의 텍스트 색상을 `var(--primary)`(밝은 흰색)으로 강제 적용(`!important`).

## 3. Pre-Merge Quiz (확인 퀴즈)
> 작업 완료 및 브랜치 병합을 위해 아래 퀴즈를 확인하시고 답변해 주세요.

**Q1. 본 작업에서 행성을 평면적인 노이즈 구체에서 '진짜 행성'처럼 입체적으로 보이게 만들기 위해 GLSL 셰이더에 새로 도입한 연산은 무엇입니까?**
1. 가상의 광원(Light Direction)과 노말 벡터를 내적(dot)하여 그림자를 생성하는 Diffuse 조명 연산
2. 해상도를 두 배로 증가시키는 Super Sampling 안티앨리어싱
3. 여러 텍스처 이미지를 다운로드하여 구체에 입히는 UV Mapping

**Q2. 마우스를 카드에 올렸을 때 어둡게 뭉개지던 검은/회색 텍스트 문제를 해결하기 위해 CSS에 추가한 규칙은 무엇입니까?**
1. `.card` 배경색을 완전히 흰색으로 변경
2. `.card:hover` 하위의 모든 요소(`*`)의 텍스트 색상을 뚜렷한 `var(--primary)`로 강제(`!important`) 적용
3. 텍스트 요소에 `text-shadow`를 극단적으로 두껍게 추가
