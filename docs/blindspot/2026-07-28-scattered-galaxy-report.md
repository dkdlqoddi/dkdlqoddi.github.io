## Human 섹션

### 요약

기존 마우스 포인터를 그림자처럼 쫓아다니던 거대한 단일 은하계를 대신하여, 화면 전체에 서로 다른 크기와 깊이(원근감)를 가진 5개의 은하를 흩뿌렸습니다.
마우스를 움직이면 멀리 있는 은하는 천천히, 가까이 있는 은하는 빠르게 부유하는 시차(Parallax) 효과를 느낄 수 있습니다. 
모바일 기기에서도 자연스럽게 반응하도록 터치 스크롤 시 화면이 튀지 않고 부드럽게 패럴랙스가 적용되며, 화면 크기를 변경해도 은하들이 쏠리지 않도록 반응형으로 설계되었습니다.

### 스크린샷 / 데모

해당 없음

### 리뷰 포인트 (개발자용)

- `scripts/galaxy.js` : 단일 배열 구조를 `galaxies` 다중 객체 배열로 리팩토링.
- `scripts/galaxy.js` : 창 리사이즈 시 비율(ratioX, ratioY) 기반 좌표 재배치 및 모션 저감 시 강제 렌더링 로직 추가.
- `scripts/galaxy.js` : 마우스 움직임 궤적을 절대 좌표에서 정규화된 오프셋(-1.0 ~ 1.0)으로 변경하고 은하 깊이(depth) 가중치 적용.

## Agent 섹션 (AI 인수인계용)

### 의도 (Intent)
단일 나선 은하 형태가 마우스 커서에 종속되어 보여 디자인적 답답함을 주던 문제를, 5개의 분산된 은하와 패럴랙스를 통해 넓은 우주 공간감으로 개편함.

### 제약 (Constraints)
- 배터리 제약(입자 총합 100개 이하, 30fps)을 유지하기 위해 Float32Array SoA 패턴 도입 대신, 기존 객체 배열 내에서 각 은하당 20개의 파티클만 할당하는 단순 배열 그룹화(AoS) 방식을 취함.

### 검토한 엣지케이스

| 엣지케이스 | 처리 |
|---|---|
| 울트라 와이드 모니터 패럴랙스 이탈 | 캔버스 중심 기준의 오프셋을 최대 -1.0 ~ 1.0 비율로 클램핑(Clamp)하여 마우스가 끝으로 가도 은하가 뷰포트 밖으로 완전히 벗어나지 않도록 방어함. |
| 리사이즈 좌표계 파손 | 고정 픽셀 좌표가 아닌 `rx=0.5, ry=0.5` 등의 스크린 비율로 은하 원점을 저장해, 리사이즈될 때마다 실시간으로 비율 좌표를 픽셀로 환산(canvas.width * rx)하도록 설계함. |
| 모바일 터치 점프 | 터치 시작(`touchstart`) 시 이벤트 대상 목표 좌표뿐만 아니라, 현재 보간(Lerp) 중인 위치까지 즉시 일치시켜 위치가 순간이동(Jump)하는 렌더 튀김 현상을 억제함. |
| 모션 저감 환경 리사이즈 블랙스크린 | `requestAnimationFrame`이 정지된 상황이더라도, `resize()` 이벤트 핸들러가 호출될 경우 `draw(..., forceRender=true)`를 호출하여 정지 프레임을 다시 찍어냄. |
