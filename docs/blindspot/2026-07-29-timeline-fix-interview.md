# Requirements Interview: Timeline Layout Fix

말씀해주신 피드백(Latency 타임라인 크기 초과 문제)을 확인했습니다. Reveal.js의 자동 스케일링 환경에서 화면 밖으로 잘리는 현상을 완벽하게 수정하기 위해, 해결 방안에 대한 세부 옵션을 여쭤봅니다.

### 인터뷰 질문 (구현 방향 확정)

**1. 타임라인(Waterfall) 레이아웃 축소 방식**
타임라인이 화면에 모두 들어오도록 조절할 때, 어떤 시각적 처리가 좋을까요?
- **[A] 수직 간격 및 폰트 축소 (권장)**: 현재 위아래로 쌓여있는 4개의 막대그래프 간격(margin)과 박스 패딩(padding)을 대폭 줄여서 기존 레이아웃을 유지한 채 높이만 압축합니다.
- **[B] 가로형(Horizontal) 프로세스로 재설계**: 세로로 쌓는 대신, `[LLM] -> [API] -> [FW] -> [MCP]` 순서대로 좌측에서 우측으로 막대가 이어지도록 가로축을 활용하여 공간을 확보합니다.

**2. 주변 텍스트 요소 밸런스 조정**
타임라인 박스 크기를 줄일 경우, 주변에 있는 설명 텍스트("총 6.3초 소요...")의 크기도 함께 줄여서 밸런스를 맞출까요?
- **[A] 네, 전체적인 비율에 맞춰 설명 텍스트 폰트도 축소해 주세요.**
- **[B] 아니오, 타임라인 박스만 줄이고 글씨 크기는 그대로 유지해 주세요.**

---

원하시는 옵션(예: "1-A, 2-A")을 말씀해 주시면, 바로 Implementation Plan을 수립하여 수정 작업에 착수하겠습니다!
