## Agent 섹션 (AI 인수인계용)

### 의도 (Intent)

cds 덱에서 검증된 패턴을 sample로 역이식하되, "대상 없는 규칙은 죽은 코드" 판례를 지키기 위해 데모 2장을 추가해 모든 규칙에 실사용처를 만들었다. sample은 이제 안내문(6장) + 표현 기법 실물 견본(2장)이다. 다음 덱 작성자의 참조 우선순위: sample 보너스 2장, 세부 응용은 cds 덱.

### 제약 (Constraints)

- sample은 slides.json 미등재 유지(방문자 비노출·URL 접근 가능) — 등록 금지.
- 데모 소재는 sample이 가르치는 절차(복사·수정·등록·공개) 재사용 — cds 서사 복제 금지.
- cds 전용 콘텐츠 클래스(.cards/.bignum/.steps/.cols/.ask/.diag.half)는 이식하지 않음(사용처 없음).
- 글자 하한 24px(0.58em), 크기는 잎 클래스 1회 지정.
- 짝 없는 요소의 자동 페이드는 데모에서 의도적으로 노출(기본 동작 시연). 억제 속성은 주석 안내만.

### 검토한 엣지케이스

### 두 덱 사이 의도적 차이 (인수인계 주의)

- `.small`: sample 0.6em / cds 0.68em — 같은 이름, 다른 크기. 덱 간 조각 복사 시 크기가 바뀐다. 테마 자유 원칙상 통일하지 않음.
- `pre` 크기 규칙: sample만 보유(0.58em). cds에는 `<pre>`가 없어 판례상 규칙을 넣지 않음 — cds에 코드 상자를 추가하는 사람은 이 규칙도 함께 가져갈 것.

### 의도적 범위 제외

- cds 덱 수정 없음(위 pre 건 포함). 랜딩·manifest·vendor 무변경.
- 데모에 `data-auto-animate-unmatched="false"` 실사용 없음 — 기본 동작 시연이 우선, 실사용례는 cds 참조로 주석 안내.
- 과거 blindspot 문서의 "견본 6장" 기록 미수정(이력 보존 판례).
