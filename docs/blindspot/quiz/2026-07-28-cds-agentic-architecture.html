변경 요약

새로 추가된 발표자료는 에이전트 연동 시스템 전체 구조를 보여줍니다. 오픈코드에서 시작해 중개 서버를 거쳐 가상 작업망까지 도달하는 연결 과정을 순서대로 보여줍니다.

가상 작업망 환경에서 담당자들이 에이전트를 위해 설정해야 할 세 가지 핵심 작업을 안내합니다. 첫째, 툴 설정값을 명시적으로 문서화해야 합니다. 둘째, 환경 스크립트는 기존 사용자의 셋업을 존중하고 단일 권한만 부여해 멈춤을 방지해야 합니다. 셋째, 단순한 검증 위반만 기계가 고치고 복잡한 에러는 사람이 승인하도록 로그 분석 기준을 마련해야 합니다.

실제 백엔드 에이전트 코드나 통신 스크립트 구현은 이번 작업에서 철저히 제외했습니다. 본 저장소는 발표자료를 담는 곳이기 때문입니다.
