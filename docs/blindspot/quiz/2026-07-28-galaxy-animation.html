변경 요약

랜딩 페이지와 모든 발표자료 슬라이드의 배경에 마우스 움직임을 따라다니는 화려한 은하수 애니메이션을 새로 추가했습니다. 배터리 소모를 막기 위해 프레임 속도와 화면 입자 수를 조절했으며, 여러 화면에서 코드가 중복되지 않도록 하나의 공통 파일을 만들어 연결했습니다. 또한 사용자가 기기 설정에서 어지럼증 방지를 켜 둔 경우, 애니메이션이 즉시 정지하고 첫 화면에서 멈춰있게 됩니다.
