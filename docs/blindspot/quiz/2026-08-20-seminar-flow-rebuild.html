Pre-Merge Quiz: 팀 세미나 흐름 재구축

변경 요약

팀 세미나를 위해 발표 자료 두 벌을 1부와 2부의 연작으로 다시 구성했습니다. 두 자료의 마지막 장에는 서로로 이동하는 링크가 생겼습니다. 이 링크는 폴더 이름을 직접 가리키며, 목록 파일 점검으로는 확인되지 않습니다. 2부는 원래 있던 연속 장면 두 장 뒤에 이번에 한 장을 이어 붙여, 같은 그림 요소가 미끄러지며 이어지는 세 장짜리 연속 장면이 됐습니다. 이 장면은 요소마다 붙은 짝 이름으로 연결됩니다. 자료를 PDF로 내보낼 때 클릭 전의 실패 표시(✗)와 클릭 후의 처리 표시(✓)가 같은 자리에 겹쳐 찍히던 결함을 찾아, 사라지는 쪽을 숨겨 최종 상태만 나가게 고쳤습니다. 각 방법·제품 장 위의 단계 표시기는 흑백 인쇄에서도 현재 칸을 알 수 있도록 현재 칸만 반전(검은 바탕, 흰 글자)으로 인쇄되게 했습니다. 모든 자료가 함께 쓰는 공통 꾸밈 파일은 일부러 건드리지 않았고, 그 대신 움직임과 표시기 규칙 일부가 두 자료에 같은 내용으로 중복해 들어갔습니다. 좁은 화면(가로 1024)에서 첫 화면 카드 두 장이 일부 겹치는 현상은 변경 전에도 같은 겹침이 있었기에, 이번 변경 탓이 아닌 기존 한계로 판정하고 카드 설명만 짧게 줄였습니다.
