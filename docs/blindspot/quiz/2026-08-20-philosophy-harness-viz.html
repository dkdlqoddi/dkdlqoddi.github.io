변경 요약

  • 발표 자료 표지 바로 다음에 개념 설명 슬라이드 2장이 추가되었습니다. 총 11장에서 14장이 되었습니다(마무리 장 포함).
  • 첫 장은 하네스(모델을 감싸는 운영 장치)가 없는 인공지능의 결과를 보여줍니다. 같은 요청을 여러 번 실행한 결과를 넓은 부채꼴 안의 점 12개로 표현합니다.
  • 다음 장으로 넘기면 넓은 부채꼴이 좁은 띠로 부드럽게 조여지는 애니메이션이 나옵니다. 4겹의 하네스(지시문, 도구 제한, 작업 절차, 검증 루프)가 함께 표시됩니다.
  • 슬라이드의 메시지: 하네스는 결과를 하나로 고정하지 않습니다. 원하는 결과가 더 자주 나오게 폭을 조입니다. 탐색이 필요한 작업에서는 일부러 폭을 넓게 둡니다.
  • 그림 색을 공통 규칙으로 바꿨습니다. 이제 브라우저 인쇄(Ctrl+P)를 하면 도형과 글자가 검정으로 또렷하게 나옵니다. 전에는 흰 종이에 연한 청록이 그대로 남았습니다.
  • 빨간 표시 색은 어두운 배경에서 잘 읽히도록 밝은 빨강으로 일부러 바꿨습니다.
  • 화살촉을 그림마다 직접 그려, 슬라이드끼리 화살촉 정의를 몰래 나눠 쓰던 구조를 없앴습니다. 방향이 뒤집혀 있던 화살표 1개도 바로잡았습니다.
  • 낭독기(화면을 읽어 주는 프로그램)용 그림 설명 12개를 추가했습니다.
  • 슬라이드 2장이 앞에 끼면서 뒷장들이 밀렸습니다. 과거에 공유한 장 번호 주소를 열면, 기대한 장보다 두 장 앞의 내용이 나옵니다. 이 밀림은 사전에 수용하기로 결정했습니다.
  • 추가로 고친 문제: 기존 도구 소개 10장의 요약 상자 마지막 항목이 원래부터 화면 밖으로 잘리고 있었습니다. 작성자에게 확인을 받아 이번에 함께 고쳤습니다. 고정 높이를 없애고 요약 글자를 조금 줄여, 이제 14장 모두 화면 안에 온전히 들어옵니다.
