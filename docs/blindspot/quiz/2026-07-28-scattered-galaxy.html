변경 요약

기존 마우스 포인터를 쫓아다니던 단일 은하계를 대신하여, 화면 곳곳에 서로 다른 크기와 원근감을 지닌 총 5개의 은하를 분산 배치했습니다. 마우스를 움직이면 멀리 있는 은하는 천천히, 가까이 있는 은하는 빠르게 부유하는 시차(Parallax) 효과를 구현했습니다. 터치 기기에서도 화면 튐 없이 부드럽게 스크롤링이 가능하며, 브라우저 화면 크기를 조절해도 반응형으로 은하들의 위치 비율이 유지됩니다.
