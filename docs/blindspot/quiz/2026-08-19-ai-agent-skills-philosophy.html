머지 전 퀴즈: AI Agent Skills Philosophy

변경 요약

  • 인공지능 코딩 도구들의 철학을 소개하는 11장의 슬라이드를 만들었습니다.
  • 글 대신 내부 작동을 보여주는 그림을 활용하여 직관적으로 도구를 이해하게 했습니다.
  • 복잡함을 막기 위해 한 페이지에 하나의 도구와 그림만 배치했습니다.
  • 외부 프로그램을 쓸 수 없는 환경이므로 도형 도구(SVG)와 글씨 색상으로만 그림을 그렸습니다.
  • 도구의 철학을 비교하는 것이 목적이므로 복잡한 명령어 예시나 상세 설정 방법은 의도적으로 제외했습니다.
