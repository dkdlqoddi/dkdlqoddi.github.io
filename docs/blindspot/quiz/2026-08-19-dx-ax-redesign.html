Pre-Merge Quiz: DX vs AX 종합 개선

변경 요약

"DX vs AX" 발표자료를 11장 새 구조로 다시 만들었습니다. 같은 작업 흐름이 규칙 기반에서 AI 기반으로 변신하는 장면이 중심입니다. 연동 방법 순서는 추상화가 낮은 것부터 높은 것 순서입니다. HTTP, OpenAI SDK, LangChain, 그리고 마지막이 opencode 위임입니다.

기존 자료의 설치 명령(pip install opencode)은 존재하지 않는 잘못된 명령이었습니다. 공식 설치 스크립트와 현행 실행 명령(opencode run)으로 정정했습니다.

다섯 발표자료에 복사되어 있던 공통 디자인을 공유 파일 하나로 모았습니다. 이 파일은 테마 파일 뒤, 각 자료의 고유 스타일 앞이라는 정해진 순서로 연결해야 합니다. 순서가 틀리면 제목이 대문자로 바뀌는 등 화면이 깨집니다.

인쇄 고장도 고쳤습니다. 전에는 종이 인쇄 시 모서리 틀과 은하 장식이 그대로 찍혔고, PDF 저장 시 긴 슬라이드가 잘리고 빈 페이지가 생겼습니다. 이제 장식은 숨겨지고 내용은 끝까지 인쇄됩니다.

"안전한 AI 설계 자동화" 발표는 깨진 한글 70줄을 복원했습니다. 그중 3줄은 원문 확정이 불가능해 문맥으로 재구성했습니다. 보이지 않던 슬라이드도 복구했습니다. 복구 직후에는 서로 다른 버전이 섞여 끝인사(THANK YOU)가 네 번 나오는 상태였습니다. 저자 확인을 받아 중복 버전을 정리했고, 삭제 전 상태는 저장 이력에 남겨 되돌릴 수 있습니다. 최종 결과는 18장, 끝인사 1회입니다.

일부러 남긴 것: 다른 발표들의 그림에 직접 적어 넣은 색은 이번에 고치지 않았습니다. 그 발표들은 종이 인쇄 시 그림 색이 검정으로 바뀌지 않습니다.
