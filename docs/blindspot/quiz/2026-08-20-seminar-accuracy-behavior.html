세미나 두 자료의 내용을 공개 자료와 대조해 틀리거나 낡은 서술을 고쳤습니다. 이미 단종된 Copilot Workspace 소개는 후속 제품 Copilot Cloud Agent 기준으로 다시 썼고, 전신 이야기는 계보 설명 한 줄로만 남겼습니다. 새 제품에서는 작업 결과가 브랜치와 세션 기록으로 남고, PR(반영 요청)은 사람이 변경 내용을 확인한 뒤 만들지 결정합니다. oh-my-opencode가 oh-my-openagent로 개명된 사실을 반영했고, 그 안의 LSP와 ast-grep은 에이전트가 아니라 에이전트들이 쓰는 도구라는 층위도 바로잡았습니다. 공식 명칭이 아닌 "LangChain Data Agent"는 LangChain Agent로 고쳤습니다. Devin은 사람이 계획을 검토·수정해야 자율 실행이 시작된다는 현재 동작으로 고쳤습니다. 2부의 도구 열 개마다 실제 사용 장면이 한 줄씩 나타나는 "동작 보기" 페이지를 추가해 2부가 17장에서 27장이 되었고, 화살표 키를 누를 때마다 한 줄씩 진행되어 전체 진행 키 입력은 약 4배(28회 → 114회)가 되었습니다. 흑백 인쇄에서도 터미널 줄 앞의 역할 기호(❯, ⛭)까지 검정으로 인쇄되도록 고쳤습니다. 정정의 근거 출처(문서·저장소 주소, ponytail 한 건은 스킬 원문 기준)는 구현 노트에 기록했습니다.
