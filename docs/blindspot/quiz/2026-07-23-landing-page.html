Pre-Merge Quiz: 발표자료 랜딩 페이지

변경 요약

  • 발표자료들을 안내하는 첫 화면(랜딩 페이지)과 예시 발표자료 1개가 만들어졌습니다.
  • 발표 목록은 목록 파일 하나로 관리합니다. 새 발표는 이 파일에 제목, 날짜, 한 줄 설명, 폴더 이름을 적어 등록합니다.
  • 목록 항목에 필수 정보(제목·날짜·폴더 이름)가 빠지면, 그 항목 하나만 목록에서 빠지고 나머지는 정상 표시됩니다.
  • 발표 도구(reveal.js)를 저장소 안에 동봉했습니다. 그래서 개별 발표자료는 인터넷 없이도 열립니다. 단, 첫 화면의 목록은 인터넷이 필요합니다.
  • 저장소에는 "자동 변환기 끄기" 파일이 있습니다. 이 파일을 지우면 자동 변환기가 켜져 배포가 실패하거나 슬라이드가 훼손될 수 있습니다.
  • 저장소에 연결된 부속 저장소(서브모듈)는 공개 상태와 HTTPS 주소를 유지해야 합니다. 어기면 사이트 배포 전체가 실패합니다.
  • 발표 폴더 이름은 영문 소문자와 하이픈만 씁니다. 폴더 이름이 곧 공유 주소가 되며, 주소는 한번 공유되면 바꾸기 어렵습니다. 이름을 자동으로 고쳐 주는 기능은 없습니다.
  • 새 발표를 공개한 뒤 방문자 화면에 목록이 반영되기까지 최대 10분 늦을 수 있습니다.
  • 지금은 아직 공개 전입니다. 머지하고 push해야 실제 사이트에 공개됩니다.
