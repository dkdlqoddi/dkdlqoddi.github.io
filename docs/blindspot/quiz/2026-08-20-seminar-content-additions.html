Pre-Merge Quiz: 세미나 덱 콘텐츠 3종 추가

변경 요약

발표 자료 2부작에 세 가지 내용이 추가되었습니다.

  • 1부 새 슬라이드 "HTTP 왕복": 내 명령은 키보드로 호출자(내 코드 또는 opencode)에게 들어갑니다. 호출자가 사내 LLM에 HTTP 요청을 보내고, 응답은 조각 스트림으로 돌아옵니다. 명령 입력 구간에는 "HTTP 아님" 표시가 붙어 있습니다. 단, 방법 5·6을 쓸 때는 내 코드가 opencode 서버에 명령 자체를 HTTP로 보냅니다. 이 경계 차이는 발표 대본과 예상 질문 14번이 설명합니다.
  • 2부 blindspot-flow 슬라이드 보강: 요약 상자에 정의 두 줄이 추가되었습니다. 맹점은 "남은 아는데 나만 못 보는 사각지대", 미지의 미지는 "모른다는 것조차 모르는 것"입니다.
  • 2부 새 슬라이드 "결과물 해부도": 망한 결과와 잘된 결과를 나란히 놓고, 부위 다섯 개를 스킬 다섯 개와 하나씩 짝지었습니다. 하네스의 도구 제한 층은 담당 스킬이 없어 행을 만들지 않았고, 캡션 한 줄이 "스킬이 아니라 하네스 몫"이라고 설명합니다.

발표 본편 시간은 새 슬라이드 2장(각 45초) 때문에 45분 45초에서 47분 15초로 늘었습니다. 45분을 엄수해야 하면 새 슬라이드 2장을 가장 먼저 통째로 건너뛰는 압축 경로가 대본에 준비되어 있습니다(44분 55초). "어떤 경우에도 유지"하는 슬라이드는 스펙트럼과 정리 두 장입니다.

슬라이드가 끼면서 뒤쪽 슬라이드의 순번이 한 칸씩 밀렸습니다. 예전 작업 보고서에 적힌 순번 링크는 옛 문서를 고치지 않고, 이번 보고서에 "삽입 전 기준"이라는 각주만 남겼습니다. 발행된 문서는 시점 기록으로 보존하는 원칙 때문입니다.

하지 않은 것: 기존 슬라이드의 발표 시간 단축, 화면 속 "여섯 가지"·"다섯" 문구 변경, 인쇄 관련 기존 문제 2건(다음 개선 사이클로 이월).
