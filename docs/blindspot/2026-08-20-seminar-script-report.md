## Agent 섹션 (AI 인수인계용)

### 의도 (Intent)

발표자가 둘째 화면·종이로 보며 진행하는 대본. reveal 스피커 노트 플러그인이 이 저장소에 없으므로(`<aside class="notes">` 무동작) 별도 마크다운이 유일한 경로.

### 제약 (Constraints)

- `[→ n]`은 덱 실물에서 추출: 고유 data-fragment-index 수 + 인덱스 없는 fragment 수 (1부 6장의 fade-out/fade-in 인덱스 공유 = 키 1회).
- 동작 보기 줄 텍스트 비복제(단일 출처) — 덱과 대본의 이중 유지보수 방지.
- 슬라이드 화면 문구를 인용할 때는 글자 단위로 일치(①→③ 등).
- 시간 라벨은 실측 합산 기준으로 정직하게(본편 44:15 ≈ 45분, 압축 약 37분/약 33분 — 그 이하는 Q&A 축소 권고).
