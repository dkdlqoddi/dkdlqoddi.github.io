# Requirements Interview: Animation Iterations & Limitation Expansion

애니메이션의 다중 이터레이션(Agentic Loop) 묘사와 한계점(Limitations) 강조 및 상세 예시 페이지 추가 피드백을 확인했습니다. 시각적 임팩트와 레이아웃 구성을 최적화하기 위해, 작업 전 3가지 세부 디자인을 결정해주시면 감사하겠습니다.

### 인터뷰 질문 (구현 방향 확정)

**1. 다중 이터레이션(Agentic Loop) 애니메이션 연출 방식**
단 한 번의 요청이 아니라 Opencode와 MCP 간에 여러 번 통신이 오가는 것을 어떻게 묘사할까요?
- **[A] 루프 카운터 및 핑퐁 효과(권장)**: 화면 중앙에 `Loop Iteration: 1..2..3..` 카운터가 올라가며, 데이터 펄스가 Opencode와 MCP 사이를 여러 번(예: 3~4회) 빠르게 왕복한 뒤 최종 결과를 출력하는 디테일한 묘사
- **[B] 동시다발적 혼돈 효과**: 여러 개의 펄스가 동시에 양방향으로 쉴 새 없이 날아다니며 에이전트의 복잡하고 바쁜 통신 상태를 강조

**2. 한계점(Limitations) 슬라이드의 시각적 강조 방식**
현재 다이어그램 위에 얹혀진 3개의 한계점이 눈에 잘 띄지 않는다는 점을 어떻게 개선할까요?
- **[A] 경고(Warning) 모드 레이아웃(권장)**: 배경 다이어그램을 어둡게(Dimmed) 처리하고, 3개의 붉은색 경고 박스를 화면 중앙에 매우 크고 강렬하게 돌출(Pulse 애니메이션)시키는 방식
- **[B] 카드 뷰(Card View) 전환**: 다이어그램을 완전히 치우고, 화면 전체를 3개의 강렬한 경고 카드로만 꽉 채우는 방식

**3. 한계점별 상세 예시 슬라이드(총 3장)의 구성 방식**
추가되는 3장의 각론 슬라이드(환각, 지연, 오버플로우)는 어떤 자료 위주로 구성할까요?
- **[A] 코드/로그 스니펫 기반**: "존재하지 않는 툴 호출"이나 "방대한 로그 데이터"를 가상의 JSON 코드나 로그 텍스트 블록으로 시각화하여 현실감을 부여 (개발자 대상)
- **[B] 은유적 다이어그램 기반**: 데이터 상자가 터져나가거나(오버플로우), 무한 쳇바퀴를 도는(지연) 시각적 메타포를 큰 아이콘/도형으로 묘사 (일반 청중 대상)
