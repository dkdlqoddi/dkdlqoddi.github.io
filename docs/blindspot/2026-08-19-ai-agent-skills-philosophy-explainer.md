## 목적과 배경

유명한 인공지능 코딩 에이전트들의 핵심 기능과 철학을 소개하는 발표자료를 제작합니다. 글 설명을 최소화하고 시스템 내부의 상호작용을 보여주는 구조도 중심의 슬라이드로 구성합니다. 발표를 듣는 사람이 각 도구의 차이점과 지향점을 한눈에 파악할 수 있도록 돕기 위함입니다.

## 결정사항

| # | 결정 | 근거 |
|---|---|---|
| 1 | 총 11장의 슬라이드 구성 (표지 1 + 스킬 소개 10개) | 한 페이지당 하나의 도구만 소개하여 가독성을 극대화하라는 사용자 요구. |
| 2 | SVG 아키텍처 다이어그램 기반의 통일된 레이아웃 | 각 도구의 '철학'을 시스템 흐름도(작동 구조)로 시각화하기로 인터뷰에서 합의함. |
| 3 | 추가 스킬 자체 선정 (Copilot, Aider, Devin, LangChain) | 코덱스와 각 분야(개발, 기획, 도메인)의 대표적인 도구를 선정하여 구성의 다양성을 확보함. |

## 검토한 대안과 트레이드오프

| 결정 | 채택안 | 기각안 | 기각 이유 |
|---|---|---|---|
| 슬라이드 정보량 제한 | 1페이지당 스킬 1개와 구조도 1개 배치 | 1페이지에 관련 스킬 2-3개를 묶어서 배치 | 그림이 작아져 다이어그램의 가독성이 떨어지고 시각 자료 중심이라는 원칙에 위배됨. |
| 철학의 표현 방식 | 시스템 흐름도로 내부 작동 방식을 명시 | 추상적 아이콘과 은유 위주의 디자인 | 인터뷰 답변 결과, 작동 방식 중심의 표현을 선호하심. |

## 동작 방식

새로 생성될 `ai-agent-skills-philosophy` 덱은 다음 구조로 동작합니다.
1. 표지와 기본 설정 화면이 나옵니다.
2. 클로드 코드 기반의 5가지 스킬(superpower, grill-me, ponytail, fablize, blindspot-flow)이 차례로 소개됩니다.
3. 오픈코드의 `oh-my-opencode`가 소개됩니다.
4. 코덱스 기반의 `Copilot Workspace`, 개발 특화 `Aider`, 기획/자율성 특화 `Devin`, 도메인 특화 `LangChain Data Agent`가 순서대로 소개됩니다.
5. 각 슬라이드는 제목 아래에 큰 SVG 다이어그램이 자리하며, 하단에 핵심 철학을 요약한 한 줄짜리 문구가 위치합니다.

## 의도적 범위 제외

- 각 도구를 직접 설치하거나 실행하는 방법, 세부 명령어 옵션 설명은 완전히 제외했습니다. 발표 목적이 도구 사용법 교육이 아니라 사상과 작동 구조를 거시적으로 비교하는 것이기 때문입니다.
