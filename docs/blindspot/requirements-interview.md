# Requirements Interview: 방법론 축소(2개) 및 통합 다이어그램 추가

## 분석 개요
사용자님의 요청(`blindspot-flow`)에 따라, 기존의 3가지 방법론 중 **"방법론 2: S3 Server 기반 우회형"을 완전히 삭제**하고 전체 흐름을 2가지 대안(MCP Server 통제형 vs VWP망 완전 격리형)으로 압축합니다. 또한 이 두 가지를 한눈에 대조할 수 있는 통합 다이어그램(SVG)을 새로 추가할 예정입니다.

### 자체 해소 (Implementation Note)
* **넘버링 수정:** 기존의 "방법론 3 (VWP망 내재화)"은 이제 **"방법론 2 (VWP망 내재화)"**로 이름과 번호가 일괄 변경됩니다. 목차 슬라이드와 결론부에서도 S3 관련 내용이 모두 삭제됩니다.
* **통합 다이어그램 설계:** 하나의 슬라이드 안에서 위쪽 절반에는 "방법론 1(Office망 LLM + MCP)", 아래쪽 절반에는 "방법론 2(VWP망 LLM + Docker)"를 상하로 배치하여, 방화벽(Firewall)을 가로지르는 트래픽의 유무를 극명하게 대조하겠습니다.

## ❓ 확인이 필요한 사항 (질문)
> 통합 다이어그램이 들어갈 슬라이드의 위치와 구성을 명확히 하기 위해 아래 내용을 확인해 주세요.

**Q1. 통합 다이어그램 슬라이드의 역할**
두 방법론을 한 장에 보여주는 새로운 시각자료(다이어그램)를 추가할 때, 기존의 구조를 어떻게 가져갈까요?
* **옵션 A (완전 교체):** 방법론 1 상세 슬라이드와 방법론 2 상세 슬라이드를 각각 보여주지 않고, 오직 **통합 다이어그램 슬라이드 1장**만 띄워서 그 자리에서 두 가지를 모두 설명하는 압축적인 구조.
* **옵션 B (요약 추가):** 기존처럼 방법론 1 슬라이드와 방법론 2 슬라이드를 순서대로 1장씩 각각 보여준 뒤, **마지막에 통합 다이어그램 슬라이드를 띄워** 두 개를 비교 요약하는 구조.

위 질문에 대해 원하시는 옵션(예: "Q1-옵션 A로 압축해주세요")을 답변해 주시면, 즉시 2개 방법론 체제로 코드를 정리하고 멋진 통합 다이어그램을 설계해 오겠습니다!
