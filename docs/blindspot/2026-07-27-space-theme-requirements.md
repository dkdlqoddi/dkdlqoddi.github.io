## 요청 배경

2026-07-30 목요일에 발표가 예정되어 있다. 이 발표는 기존 발표 자료(cds-agentic-work)를 그대로 다시 사용한다. 새 발표 자료는 만들지 않는다. 발표 전에 사이트 전체의 분위기를 바꾸고 싶다는 요청이다. 목표는 "흰색 우주선이 우주를 유영하는" 고요한 분위기다. 디자인과 움직임(애니메이션)은 참고 사이트 euiyun.com을 참고한다. 특히 한글 글꼴과 글씨체를 중요하게 다룬다. 재사용 발표에 맞춘 발표자 표기와 날짜 정정도 이번 범위에 포함한다.

## 확정 요구사항

1. **작업 범위는 방문자가 보는 페이지 전부다.** 목록 페이지(첫 화면), 기존 발표 자료(cds-agentic-work), 견본(sample), 404 페이지를 같은 테마로 통일한다. 404 페이지는 색 반전만 하고, 별과 우주선은 넣지 않는다. (정정 2026-07-27: 404는 상대 경로가 깨지는 페이지라 동봉 글꼴을 적용하지 않고 시스템 글꼴을 유지한다 — unknowns 3번) `docs/blindspot/` 아래 문서와 퀴즈 HTML은 시각 테마 적용 대상에서 제외한다. 규칙 문서의 내용 갱신은 별개이며 11번에서 정한다. — 근거: "전부 (목록 페이지 포함)" 답변.
2. **배경은 어두운 우주로 반전한다.** 검은 배경에 흰 글자와 흰 별을 쓴다. 발표 자료는 동봉된 reveal.js black 테마를 기반으로 만든다. 이전 요구사항의 "흰 바탕에 검은색" 구성 조항(2026-07-23 문서 6번)도 이 답변으로 대체된다. — 근거: "어두운 우주로 반전" 답변. (정정 2026-07-27: 실제 값은 순검정·순백이 아니라 unknowns 5번 팔레트 — 배경 #0e0e0e, 기본 글자 #dedede 등)
3. **테마 통일은 이번 작업 대상에 한정한다.** "발표 자료마다 테마를 자유롭게 고른다"는 이전 원칙은 앞으로 만들 자료에 대해 그대로 유지한다. 견본(sample)의 기본값이 어두운 테마로 바뀔 뿐이다. — 자체 해소: 인터뷰의 "전부"는 작업 범위에 대한 답변이지 영구 규칙 선언이 아니다.
4. **흰 우주선은 첫 화면과 발표 자료 표지에만 등장한다.** 단순한 흰 실루엣이 천천히 떠다닌다. 내용 슬라이드에는 우주선을 넣지 않는다. — 근거: "첫 화면·표지에만 우주선" 답변.
5. **이전의 "우주선 형상 묘사 금지" 결정은 해제한다.** 2026-07-23 첫 화면 요구사항 6번("느낌만 살리고 그림은 넣지 않는다")은 이번 답변으로 대체된다. 단, 사진이나 비트맵 그림 파일 추가 금지는 계속 유지한다. — 근거: "첫 화면·표지에만 우주선" 답변이 형상 등장을 전제한다.
6. **우주선은 코드로만 그린다.** CSS 도형 또는 문서 안에 직접 쓰는 SVG(인라인 SVG)로 그린다. — 자체 해소: 사이트 콘텐츠에는 이미지 파일이 없다는 관례를 유지한다.
7. **움직임 기준은 대상별로 다음과 같이 못박는다.** 내용 슬라이드의 장식은 별 배경까지만 허용한다. — 자체 해소: "집중 방해 최소화" 선호를 정량화했다.

   | 대상 | 허용 움직임 |
   |---|---|
   | 첫 화면의 별 | 정지 또는 주기 140초 이상의 미세한 흐름 |
   | 발표 자료의 별 (표지·내용 슬라이드) | 첫 화면과 같은 기준 |
   | 우주선 (첫 화면·표지) | 주기 6초 이상, 이동량 8px 이하의 부유 |
   | 글자와 도형 | 등장할 때만 0.7초에서 1.2초 움직이고, 등장 후 정지 |
8. **발표자 표기는 "우제율"이다.** 기존 발표 자료 표지의 "우재율"도 "우제율"로 고친다. — 근거: "우제율 (이번 요청대로)" 답변.
9. **발표 날짜 기록은 2026-07-30으로 갱신한다.** 발표 자료 표지의 날짜와 목록 데이터(slides.json)의 날짜를 함께 고친다. 이 자료의 공식 발표일은 7월 30일로 남는다. — 근거: "2026-07-30으로 갱신" 답변.
10. **한글 글꼴은 Pretendard(프리텐다드)를 저장소에 동봉한다.** 첫 화면과 발표 자료 모두 이 글꼴을 담은 CSS를 상대 경로로 참조한다. — 자체 해소: "한글 폰트 중시" 요청과 "외부 서버 금지" 원칙을 함께 지키는 길은 동봉뿐이다. (정정 2026-07-27: 동봉 형태는 원본 파일이 아니라, 글꼴 데이터를 base64로 내장한 CSS 1개 + 라이선스 파일이다. 인터넷 없는 환경에서 브라우저가 별도 글꼴 파일을 차단하는 문제를 피하는 유일한 방식 — unknowns 1·2번)
11. **글꼴 동봉은 이전 결정 두 가지를 대체한다.** (a) 첫 화면이 외부 서버(jsDelivr CDN)에서 글꼴을 받던 방식을 폐기한다. (b) "발표 자료의 한글은 시스템 글꼴로 둔다"던 수용 사항을 폐기한다. 첫 화면이 온라인 전용이라 CDN이 무방하다던 전제는, 로딩 경로를 하나로 통일하는 이번 결정으로 무효가 된다. 갱신할 규칙 문서는 세 곳으로 한정한다: CLAUDE.md(덱 작성 규칙 절과 Architecture 절의 랜딩 설명), README.md(외부 리소스 안내), 견본(sample)의 안내 주석. — 자체 해소: 발표 자료 규칙을 첫 화면까지 확대 적용하는 것이다. (정정 2026-07-27: 견본 갱신 범위는 안내 주석뿐 아니라 본문 슬라이드의 규칙 문구까지 포함한다 — unknowns 12번)
12. **글꼴 파일은 수정 없이 그대로 복사한다.** Pretendard의 라이선스(OFL)는 "Pretendard"라는 이름을 예약(RFN)해 두었다. 원본을 수정 없이 복사하면 이 이름을 그대로 쓸 수 있다. 글자 수를 줄이는 가공(서브셋)을 하면 이름을 바꿔야 하므로, 가공하지 않는다. — 자체 해소: 라이선스 조사 결과. (정정 2026-07-27: "복사"의 형태는 원본 데이터를 바꾸지 않고 CSS 안에 내장(base64)하는 것이다. 가공 금지는 그대로 유지된다 — unknowns 1번)
13. **euiyun.com에서는 수치와 질감만 가져온다.** — 자체 해소: 참고 사이트 조사 결과를 "값 차용"으로 한정했다.
   - 가져올 값: 제목 자간 −0.025em. 본문 자간은 0에서 −0.01em 사이.
   - 가져올 값: 감속 곡선 cubic-bezier(0.16, 1, 0.3, 1).
   - 가져올 값: 모션의 시간과 이동량 기준은 7번 표를 따른다.
   - 가져오지 않을 것: 여러 색 강조(악센트), 고속으로 움직이는 다수 입자 배경, 외부 서버 글꼴 로딩. 입자 배경은 집중 방해 최소화 선호와, 외부 로딩은 하드 제약과 충돌한다.
   - 별 배경은 여기서 말한 입자 배경에 해당하지 않으며, 7번 기준을 따른다.
14. **무채색을 유지한다.** 강조 색 0개라는 이전 결정을 어두운 배경에서도 그대로 지킨다. — 자체 해소: 첫 화면 구현 노트의 확정 결정이며, 흰 우주선 컨셉과도 맞는다.
15. **움직임 줄이기 설정을 존중한다.** 운영체제에서 "움직임 줄이기"를 켠 사용자에게는 모든 유영 모션을 정지한다. 기존 발표 자료에는 페이지 전환에만 이 처리가 있으므로, 새로 넣는 유영 모션까지 범위를 넓힌다. — 자체 해소: 접근성 기본 사항.
16. **발표 자료는 인터넷 없이 열려야 한다.** 글꼴을 포함한 모든 파일을 상대 경로로 참조한다. — 자체 해소: 기존 하드 제약 유지.
