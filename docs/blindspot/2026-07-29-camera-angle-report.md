# Work Report & Pre-Merge Quiz: Galaxy Camera View Angle Adjustment

- 날짜: 2026-07-29
- 상태: 은하수를 렌더링하는 카메라의 초기 Y축 시야각(phi) 하향 조정 완료

## 작업 요약 (Implementation Summary)
1. **카메라 앵글(Phi) 수정**: `scripts/galaxy3d.js` 내에 정의된 구면 좌표계 카메라 변수 중, 위아래 각도를 관장하는 `phi` 변수의 기본값을 `Math.PI / 3` (약 60도, 위에서 내려다보는 시점)에서 `Math.PI * 0.45` (약 81도, 거의 수평에 가까운 시점)로 조정했습니다.
2. **초기 로딩 시점 동기화**: 카메라가 처음 생성될 때 애니메이션 계산 전 잠시 다른 각도에서 시작하여 "점프(Jump)"하는 현상을 막기 위해, `camera.position.set()`에 들어가는 초기 XYZ 좌표 역시 방금 수정한 `targetCameraX, Y, Z` 값을 그대로 물려받도록 개선했습니다.
3. 이제 첫 화면 진입 시 거대한 3D 은하수를 좀 더 옆면(측면)에서 웅장하게 바라볼 수 있습니다!

아래 퀴즈의 정답을 골라주시면 즉시 깃 커밋(Commit) 프로세스를 진행합니다!

**Q. 이번 작업에서 은하수를 좀 더 옆면(측면)에서 바라보기 위해 수정한 `phi` 값은 구면 좌표계(Spherical Coordinates)에서 어떤 각도를 의미할까요?**
1) Y축(위쪽)을 기준으로 카메라가 얼마나 내려와 있는지를 나타내는 고도각 (0은 정수리 위, 90도는 정측면)
2) XZ 평면(바닥)을 기준으로 카메라가 좌우로 얼마나 회전했는지를 나타내는 방위각
3) 카메라 렌즈의 시야각(FOV)을 넓혀서 광각 렌즈처럼 왜곡시키는 배율 값
