## 2026-07-27 15:10 — 별 개수: 랜딩 80개, 덱 34개

- 결정: 랜딩 별은 2px 40개 + 1px 40개 = 80개(설계 범위 60~90 내). 덱 별은 2px 18개 + 1px 16개 = 34개로 랜딩보다 줄이고 더 흐리게(0.4/0.22) 했다. 상단·하단 가장자리(102~103vh) 여유 별로 drift 공백을 메웠다.

- 검토한 대안: 덱도 80개 — 기각(집중 방해).
- 보수적 선택 여부: 예 (덱 장식을 더 줄이는 쪽)
- 계획과의 이탈: 없음 (설계는 랜딩 개수만 60~90으로 못박음)
