# Work Report & Pre-Merge Quiz: Marker Opacity & HUD Theme

- 날짜: 2026-07-29
- 상태: 도입부 마커 투명도 연동 및 랜딩 페이지 테마 강화 완료

## 작업 요약 (Implementation Summary)
1. **마커 및 연결선 스크롤 연동 완벽 적용**: 도입부에 화면이 깨끗하게 보이도록 발표자료 카드가 숨겨져 있을 때, 우주 공간상의 `Mesh`(행성 마커)와 SVG 연결선들도 같이 보이지 않도록 수정했습니다.
   - 3D 셰이더 내부에 투명도를 관장하는 `uOpacity` 변수를 주입하고 자바스크립트의 스크롤 상태(`body.scrolled`)를 셰이더 변수로 전달하여, 카드와 동일한 타이밍에 스무스하게 나타나도록 렌더링 파이프라인을 개선했습니다.
2. **랜딩 페이지 HUD(Rocket Lab) 테마 적용**: 일반적인 웹페이지처럼 보였던 랜딩 페이지 요소들을 우주선 내비게이션(HUD) 느낌으로 개편했습니다. 
   - 메인 타이틀에 네온 글로우(빛 번짐) 효과를 넣고, 부가 설명(Eyebrow)과 로그 카운트, 푸터 텍스트에 사이버틱한 시안(Cyan) 색상을 적용해 3D 은하수와 혼연일체가 되도록 스타일을 강화했습니다. 화살표에는 둥둥 떠다니는 듯한 바운스 애니메이션도 곁들였습니다.

## Pre-Merge Quiz (Blindspot Check)

아래 퀴즈의 정답을 골라주시면 즉시 깃 커밋(Commit) 프로세스를 진행합니다!

**Q. 스크롤을 내리지 않은 최초 진입 상태일 때, 기존에는 3D 행성(마커)들이 화면에 항상 떠 있었습니다. 이번 작업에서 HTML 카드와 똑같이 마커들이 스르륵(Fade-in) 나타나도록 만들기 위해 3D 캔버스 측에 추가한 조치는 무엇일까요?**
1) HTML의 `opacity: 0` CSS 코드를 캔버스 태그 전체에 강제로 적용하여 캔버스 자체를 투명하게 만들었다.
2) 마우스 호버(`uHover`)와 유사하게 셰이더 내부에 투명도를 결정하는 `uOpacity` 변수를 추가한 뒤, 자바스크립트에서 스크롤 여부에 따라 이 값을 0.0에서 1.0으로 부드럽게 넘겨주었다.
3) 스크롤을 내리기 전까지는 브라우저가 Three.js 엔진을 아예 실행시키지 않도록 로딩 시점을 지연시켰다.
